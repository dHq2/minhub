# 굴의 프롤로그 (cave-game)

현재 버전: v7.4

## 구성

- `index.html` — 게임 전체 (한 파일). 그대로 브라우저로 열어도 되고, 아티팩트로도 게시됨.
- `assets/` — 원화 스프라이트 시트(가로로 이어진 프레임), 얼굴 초상화, 스킬 아이콘 PNG.
- `data/drops.csv` — 낙하 목록. 엑셀로 열어 행을 추가하거나 고치면 게임에 바로 반영됨.
- `README.md` — 이 문서. 설계 메모 + 변경 기록.

## 낙하 목록 (data/drops.csv) 작성법

| 열 | 뜻 | 예시 |
|---|---|---|
| 종류 | 물건, 시체, 유물, 날씨, 특수 | 물건 |
| 이모지 | 떨어질 때 보이는 그림 | 🛡️ |
| 이름 | [ ] 안에 들어갈 이름 | 낡은 방패 |
| 설명 | 한 줄 설명 | 쪼개면 장작이 됩니다. |
| 변동 | 창고에 반영될 내용, 띄어쓰기로 여러 개 | 🍖+2 ⚙️+2 |
| 가중치 | 뽑힐 확률 비중. 0이면 무작위로는 안 나옴 | 8 |
| 최소턴 / 최대턴 | 나올 수 있는 턴 범위. 둘 다 1이면 첫 낙하에 반드시 등장 | 1 / (비움) |
| 마지막칸 | Y면 낙하 마지막 칸 전용 (날씨, 특수 이벤트) | Y |

변동 칸에 쓸 수 있는 것
- 자원: `🍖+2` `🥫+1` `🪵+3` `🪨+4` `⚙️+2` `🔥+3` `🌿+1` `💉+1` `🐌+3` (빼기는 `-`)
- `보관`: 물건 자체를 창고에 넣음
- `유물`: 🌟 유물 칸에 넣음 (설명이 INFO가 됨, 같은 유물은 두 번 안 나옴)
- `날씨:비:10` / `날씨:뇌우:4` / `날씨:눈:4`

엑셀에서 저장할 때는 "CSV UTF-8" 형식으로 저장해야 한글과 이모지가 안 깨짐.

## 지금까지의 구상

### 프롤로그: 노말모드

1. 캐릭터 커스터마이징 (텍스트)
   - 이름 → 성별 → 종족 → 직업 → 머리색(여자만) → 옷 색 → 한마디
   - 여자: 단발머리 / 남자: 대머리
   - 종족: 인간, 고블린, 엘프, 드워프 (체구와 피부색, 귀, 수염이 달라짐)
   - 직업에 따라 시작 무기가 달라짐 (기사 롱소드, 광부 곡괭이, 마법사 지팡이, 도적 단검)
   - 브라우저에 저장되고, 다음에 열면 이어서 할지 물어봄
2. 굴 (로비)
   - 2D 횡스크롤에 3D 느낌을 준 비스듬한 바닥
   - 모든 맵 공통 규칙: 세로 5칸 × 가로로 맵 길이
   - 굴은 우물 같은 공간이라 가로 14칸, 카메라 고정으로 한 화면에 다 보임
   - 석문은 바닥 오른쪽 대각선 테두리 위에 반투명하게 서 있음
   - 폰(캐릭터)은 림월드처럼 단색 도형 + 굵은 외곽선으로 조합
3. 턴과 낙하
   - 1턴 = 실제 20초 (⏸ / ▶ / ▶▶ 4배속), 4턴 = 하루
   - 첫 입장 때 첫 낙하 (시작 유물 두 개 고정), 이후 20배수 턴마다 낙하
   - 낙하는 모닥불로 3~10개가 떨어지고, 화면 가운데 이벤트 창에 목록이 뜨며 창고에 바로 반영
   - 마지막 칸은 가끔 날씨나 특수 이벤트, 유물은 한 번에 최대 2개
   - 창고 [C]: 자원 8종, 가축, 물건, 🌟 유물 (눌러서 INFO 조사)
   - 날씨는 우물 입구로 비나 눈이 들어오고, 뇌우는 번쩍임

4. 이동
   - 칸 단위가 아니라 속도값(칸/초)으로 걷고, 방향키 조합으로 대각선 이동
   - 키를 떼면 관성으로 조금 미끄러지다 멈춤
5. 캐릭터 창
   - 캐릭터 바의 초상화를 누르면 상태창 / 장비창 (탭)
   - 스탯표 [P]: 전원의 스탯을 한눈에, 줄을 누르면 상태창
   - 낙하 목록 [L]: data/drops.csv 를 종류별 탭으로 (비중 %, 등장 턴, 보유 여부)
6. 레베카 구출
   - 레베카에게 한 번 말을 걸면 부탁을 받고, 이후 Space로 흙 파내기 (20%씩)
   - 100%가 되면 강제 스토리 진행 (대사), 끝나면 합류해서 자유 행동 (모닥불, 하늘 바라보기, 산책)
7. 훈련장 [B] — 자동 전투, 난전
   - 목록의 캐릭터 얼굴을 바닥으로 끌어다 놓으면 그 칸에 배치 (끄는 동안 놓일 칸이 진하게 표시)
   - 조작: 빈 바닥 좌클릭 소환 · 폰 좌클릭 복사 · 폰 우클릭 삭제 · 폰 드래그 칸 이동 (커서를 올리면 금색 외곽선)
   - 아군도 복사 가능, 시체는 연한 붉은 웅덩이 위에 조용히 누운 채 남음
   - 주인공은 기본 100% 직접 조작 (AI가 대신 움직이거나 공격하지 않음). "주인공 자동 전투" 체크하면 AI에게 맡김
   - 키: 방향키 이동 · Shift 누르고 있기 달리기(x1.5) · C 공격 · X 누르고 있기 방어 (이동 30% 느려짐) · Z 회피 스텝 (방어를 풀어야 가능) · Space 전투 시작/정지
   - C 공격: 사거리 안의 가장 가까운 적을 향해 휘두름, 없으면 바라보는 쪽으로 헛스윙. 0.35초 입력 버퍼
   - 전투 화면 아래에 키 안내 줄
   - 전투 중 1턴 = 1초

8. 전투 규칙
   - 공격 순서: 준비 동작(머리 위 "!", 무기를 뒤로 들어올림) → 타격 (휘두르며 흰 베기 궤적)
   - 무기 모양: 기사 장검, 광부 곡괭이, 마법사 지팡이, 도적·고블린 단검, 레베카 긴 장검. 방어 중엔 무기를 앞으로 세움
   - 카리우스: 준비할 때 윗팔 둘을 뒤로 젖히고, 두 번의 타격을 좌우 주먹으로 번갈아 내지름 (속도선). 방어 땐 팔 넷을 앞으로
   - 타격 판정: 회피 → (방어 자세면) 막기 → 치명타(x3) → 방어력 → 막기 감소 (최소 1)
   - 방어력: 피해 감소율 = 방어력 ÷ (방어력 + 30). 방어력 10이면 25%, 22면 42%
     - 총알 · 화살은 방패(= 방탄)가 있을 때만 방어력이 먹힘. 방패가 없으면 무방비로 쏘일 때 갑옷도 소용없음
   - 막기율: 방어 자세에서 맞으면 이 확률로 막기 (최대 90%)
     - 막기 성공: 방패 60% 감소, 맨몸 30% 감소. 막으면 출혈 없음, 밀려나지 않음
     - 성공 중 10%는 정확한 타이밍 → 튕겨냄 (피해 0). 방패 · 방탄이면 총알 · 화살이 튕겨서 맵 밖으로 날아감, 맨몸이면 튕기는 연출 없이 막기만
     - 주인공의 저스트 방어 (X 타이밍)는 늘 튕겨냄 (피해 0), 그중 3%는 상대 경직 + 확정 치명타 반격
     - 막기 실패: "방어 뚫림!" 그대로 맞음 (방어력은 적용)
   - 방패 = 방탄. 방패를 가진 캐릭터는 늘 방탄 (막기 60%, 총알 · 화살에도 방어력, 튕겨내면 탄이 튕겨 나감)
     - 장비: 레베카 🛡️ 기사 방패 · 포렌 🗡 에메랄드 대검 (방패 겸용) · 쥐 기사 🛡 방패
     - 특성: 카리우스 🧬 개조된 신체 · 적뢰 🗿 대리석 피부
     - 표기: 스킬 줄의 🛡️ "방패 · 방탄" 아이콘, 스탯의 "방패 · 방탄" 줄 (출처: 장비 / 특성), 장비창의 방패 칸, 전투 중 체력바 왼쪽 🛡️
   - 무게: 넉백만 담당 (막기 계산에서 빠짐)
   - 방어 성공 연출: 파란 방패가 커지며 번쩍, 충격파, 파란 불꽃, "막음!", 잠깐 멈춤, 공격한 쪽이 튕겨 물러남. 방어 실패는 "방어 뚫림!"
   - 저스트 방어: "!"가 뜨고 맞기 직전 0.35초 안에 X를 누르면 3% 확률로 튕겨냄 → 상대 0.9초 경직, 주인공이 확정 치명타로 즉시 반격
   - 회피 스텝 (Z): 누른 방향(없으면 적 반대쪽)으로 짧게 빠지며 잔상, 0.3초 동안 회피율 최소 50%, 재사용 0.7초
   - 저스트 회피: 맞기 직전 0.35초 안에 Z → 확실히 피하고, 3% 확률로 "역전의 기회!" → 상대 0.8초 경직, 확정 치명타 반격
   - 반격 치명타: "반격!"이 뜨고, 별 파티클이 터져 바닥에 통통 튄다
   - 화살: 실제로 날아가며, 도착했을 때 대상이 자리를 떴으면 빗나감. 화살을 저스트 방어/회피하면 금색 화살로 되받아쳐 확정 치명타
   - 테스트용 체크박스: 튕겨내기 · 역전의 기회 100%
   - 무게: 맞았을 때 버틸 확률 = 내 무게 ÷ (내 무게 + 상대 무게), 치명타면 버틸 확률 x0.6. 못 버티면 뒤로 밀려나고 준비 중이던 공격이 끊김
   - 출혈: 맞으면 12% (치명타 50%, 카리우스는 절반) 확률, 5턴 동안 매 턴 중첩 × (2 + 최대체력 2%, 최대 6) 피해, 최대 3중첩
   - 감전 (1턴 = 1초, 매 턴 짧은 경직): 감전: 적뢰 (붉은 번개) 10씩 5턴 · 잔류 5씩 5턴
     - 겹치면 중첩 (최대 5중첩, 틱 피해 x중첩, 센 쪽 기준). 운 나쁘게 잔류가 겹겹이 쌓이면 재수 없게 죽음. 체력바 옆 "⚡잔류x3"
   - 공중 상태: 날려진 폰은 포물선으로 떠서 날아가고, 떠 있는 동안 잔류 면역

9. 스킬
   - 상태창의 체력 바로 아래에 스킬 아이콘 줄. 모든 아이콘은 같은 금테, 오른쪽 아래 점은 빨강=액티브 / 초록=패시브
   - 아이콘에 커서를 올리거나 누르면 아래에 상세 설명
   - 원화 아이콘: 천벌: 적뢰, 충성, 응급처치 / 나머지는 이모지 아이콘
   - 주인공: 대장, 저스트 방어, 역전의 기회 · 레베카: 불사 · 카리우스: 개조된 신체 · 청광묵: 발화 · 모닝스타: 광기 · 포렌: 충성, 쥐들의 대왕 · 노먼: 응급처치, 사수 · 적뢰: 천벌: 적뢰, 날아차기

10. 포렌 패시브 <충성> — 물량전
   - 게이지 하나가 계속 참. 다음 쥐를 미리 정하고, 쥐에 따라 게이지 길이만 다름 (전투 시작부터 바로, 운 좋으면 0.8초 만에 뿅)
   - 쥐는 아군 진형 안(무작위 아군 곁 조금 뒤)에서 적 쪽으로 튀어나옴 (최대 24마리, 가득이면 MAX)
   - 게이지 색으로 다음 쥐를 짐작: 밝은 초록 = 작은 쥐, 진한 초록 = 쥐, 더 진한 초록 = 큰 쥐 · 쥐 기사
   - 평균 약 2.8초에 한 마리 (0.58×0.8 + 0.27×3 + 0.15×8, 약 2.5초)

   | 쥐 | 확률 | 게이지 | 🫀 | ⚔ | 특징 |
   |---|---|---|---|---|---|
   | 작은 쥐 | 58% | 0.8초 | 15 | 3 | 이동 3.8, 회피 30% |
   | 쥐 | 27% | 3초 | 40 | 7 | |
   | 사람만 한 쥐 | 13% | 8초 | 200 | 14 | 70kg |
   | 쥐 기사 | 2% | 8초 | 90 | 13 | 방어력 10, 막기율 64%, 방패와 창 |

   - 작은 쥐 · 쥐 · 큰 쥐는 방어도 후퇴도 없이 무조건 공격 (적의 "!"에도 막지 않고, 방어율 0). 방어는 쥐 기사만
   - 작은 쥐 · 쥐의 행동 (막지 않음)
     - 주인 보조: 포렌이 싸우는 적에게 몰려들어 지그재그로 달려들고, 붙어서도 이리저리 쏘다니며 틈나면 묾
     - 흩어짐: 가끔 맵 여기저기 아무 곳으로 흩어져 돌아다님 (가는 길에 사거리 안 적은 묾)
     - 도망: 갑자기 뒤로 쌩 도망갔다가 (0.45~0.9초, 속도 1.8배) 다시 옴
     - 바퀴벌레 회피: 적이 자기를 치려고 "!"를 띄우면 (작은 쥐 55%, 쥐 40%) 옆으로 쌩 (0.2~0.3초, 속도 2.6배). 낙뢰 표시나 날아차기 경로에서도 옆으로 쌩
     - 가끔 "찍!" "찍찍"
   - 쥐 기사: 긴 머리에 창을 든 소녀. 앞줄에서 창 길이만큼 거리를 유지하며 자주 방어하고, 틈틈이 찌름
   - 돌격: 적과 멀면 가끔 "이야아아아!!" / "으아아아!" 흔들리는 말풍선과 함께 방패를 앞세우고 돌진
     - 돌격 중에는 방어가 항상 켜져 있음 (방어 감속 없음). 방어가 뚫리면 "돌격 저지"로 취소
     - 부딪히면 피해 16 + 대상의 행동을 0.8초 끊음 (준비 중인 공격도 취소)
   - 발동 모션(아이콘 파앗)은 전투 시작, 쥐, 큰 쥐, 쥐 기사일 때. 로그는 큰 쥐, 쥐 기사일 때만 (작은 쥐로 화면이 도배되지 않게)
   - 검은 털에 초록으로 빛나는 눈. 쥐 기사는 쥐 귀와 꼬리를 가진 작은 여기사 (청광묵 정도 크기)
   - 훈련장 목록의 "소환수"에서 각 쥐를 직접 배치해 볼 수 있음
