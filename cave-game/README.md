# 굴의 프롤로그 (cave-game)

현재 버전: v13.2

## 구성

- `index.html` — 게임 전체 (한 파일). 브라우저로 바로 열어도 되고, 아티팩트로도 게시됨
- `assets/` — 가공한 원화 (스프라이트 · 얼굴 · 배경 · 만남 그림). 원본 원화는 두지 않음
- `README.md` — 지금 게임이 어떻게 돌아가는지 + 변경 기록
- `DESIGN.md` — 구상 노트 (앞으로 만들 것, 자체 버전)

## 한눈에

인주와 동료들을 데리고 굴 아래 다섯 층을 내려가는 로그라이크. 한 판 20~30분.
전멸하면 굴로 돌아오고, 레벨과 만난 동료만 남는다. 다섯 번째 층의 바닥, 하늘이 보이는 우물 아래에서 적뢰가 기다린다.

## 굴 (로비)

- 레베카 · 카리우스 · 청광묵이 모닥불 곁에서 쉬거나 석문을 판다. 곁에서 Space로 말걸기
- 화면 위: 최고 층 · 돌파 횟수 · 동료 수
- 오른쪽 끝 석문에서 Space → 편성 → 다섯 층. 석문 앞에서는 늘 석문이 먼저 (곁에서 동료가 곡괭이질 중이어도)
- 훈련장 [B]: 모든 인물 · 적을 끌어다 놓고 전투를 시험. 스탯표 [P]: 동료 · 적 · 보스 능력치와 최근 판 기록

## 한 판

1. 편성: 인주 + 최대 4명, 각자 전열 / 후열
2. 층마다 갈림길 3번 → 보스 문 앞 모닥불 → 보스
3. 갈림길: 카드 3장 중 하나 (맨 처음 갈림길만 싸움 2장 중 하나). ⚔ 싸움 · ☠ 강적 (카드에 적 무리가 적혀 있음) · ❓ 만남 · 🔥 모닥불 · 🎴 운명의 제단
4. 5층 적뢰를 쓰러뜨리면 돌파. 전멸하면 하얀 방 → 굴
5. 판이 끝나면 결과 화면: 쓰러진 층 · 이긴 싸움 · 모은 금화 · 유물 · 레벨 변화
6. 두 번째 판부터는 이미 본 장면의 나레이션이 첫 줄 자막으로 짧아짐 (세자르의 관 장면도 짧게)

| 남는 것 (영구) | 이번 판만 |
|---|---|
| 레벨: 이긴 싸움마다 경험치, 레벨마다 체력 · 공격력 +12% | 유물 · 금화 · 단련 |
| 만난 동료: 굴에서 다음 편성에 넣음 | 최대 체력을 바친 대가 (손가락 · 등불) |

- 다음 레벨까지 경험치 60 + 레벨 × 40. 싸움 40 + 층 × 4, 강적 64 + 층 × 6, 보스 130 · 150 · 170 · 200 · 300
- 쓰러진 동료는 이기면 체력 20%로 일어남 (낡은 붕대가 있으면 35%). 레베카는 전투 중에도 일어남
- 적은 층마다 체력 · 공격력 (기술 피해 포함) +16%. 보스는 장면마다 정한 세기 (세자르 85% · 적뢰 80%, 나머지는 원래 그대로)
- 깊이: 다섯 층을 돌파할 때마다 다음 판부터 모든 적 (보스 포함) +15%. 굴 화면 위에 "돌파 N · 깊이 N (적 +N%)"

## 얻고 잃기

| 어디서 | 무엇 |
|---|---|
| 싸움을 이기면 | 금화 + 운명의 카드: 엎어진 3장 중 1장. ★ 60% · ★★ 28% · ★★★ 10% · ★★★★ 2%. ★은 회복 25% · 금화 · 가끔 유물, ★★는 금화 또는 유물, ★★★ 이상은 유물. 드물게 저주 (대신 금화 45) |
| 강적을 이기면 | 금화 많이 + 앞면 유물 3장 중 고름 (★★ 이상) |
| 보스를 이기면 | 금화 + ★★★ 이상 유물 고르기 + 모두 회복 30% |
| 운명의 제단 | 금화 30부터 1장씩 (이번 판에 뒤집을 때마다 10씩 비싸짐). 또는 유물 하나를 바치면 한 등급 위 유물 카드 3장이 엎어짐 → 하나를 뒤집음 |
| 모닥불 (갈림길 · 보스 문 앞) | 쉰다 (모두 40%) · 단련 (동료 하나 카드 1장: 체력 +15% · 공격 +10% · 방어 +3 · 인주만 투창 +30%) · 정화 (저주 하나를 태움) |

## 투창 (인주)

- F (모바일 🔱). 0.3초 들어 올려 던짐 → 초당 14칸, 최대 7칸
- 처음 맞은 적: 공격력 x2.4 + 0.5초 휘청 + 조금 밀림. 창은 그 적 바로 앞 바닥에 꽂힘
- 맨손일 땐 주먹 (사거리 1칸, 공격력 x0.6, 간격 0.7초). 꽂힌 창 위를 지나가면 주움. 전투가 끝나면 저절로 돌아옴
- 자동 인주: 2.6~7칸 떨어진 적에게 가끔 던지고, 붙은 적이 없으면 주우러 감

| 2 | 안개 늪 | 색을 잃은 자 떼 · 고블린 · 고블린 궁수 | 벤킨 + 무리 | 낙오자 헤론 · 우산 소녀 · 영입 | 구르 · 테헤라 · 노먼 · 포렌 · 옐로 | 방앗간지기 오르소 (색을 잃은 자들이 모여듦), 이기면 모닝스타 |

| 등급 | 유물 |
|---|---|
| ★ | ⛑ 녹슨 투구 (방어 +2) · 🔥 모닥불 재 (이기면 체력 10%) · 💰 빵 부스러기 동전 (금화 +25%) · ☝ 굳은 손가락 (치명타 +4%) · 🩹 낡은 붕대 (쓰러졌던 동료 35%로) · 🌫 회색 가루 (적 이동 -8%) |
| ★★ | ⛓ 쇠사슬 고리 (12%로 적이 휘청) · 🏮 붉은 등불 (시작 4초 받는 피해 절반) · 🕸 어부의 그물 (투창에 맞은 적 1.5초 묶임) · ⚙ 멈춘 맷돌 조각 (무게 +25) · 🥀 가시 장미 (맞으면 때린 적에게 4) · 💨 안개 주머니 (회피 +5%) |
| ★★★ | 🔱 되돌아오는 창 (2.5초 뒤 손으로) · 👑 녹슬지 않는 왕관 조각 (공격 +12%) · 🕯 촛불 심지 (초당 체력 1) · 🗡 청검 파편 (인주 공격 · 투창 +25%) |
| ★★★★ | 🪶 붉은 날개 깃털 (한 번, 쓰러진 동료가 그 자리에서 일어남) · 🎭 오딜의 가면 (전투마다 적 하나 3초 멍함) |
| 저주 | 🪞 깨진 거울 (받는 피해 +10%) · ⚓ 무거운 닻 (이동 -10%) · 👛 텅 빈 지갑 (금화 -50%) |

유물은 파티 전체에 붙음 (청검 파편만 인주). 던전 위쪽 칸의 유물 아이콘을 누르면 설명, 전투 중에는 지휘 줄 아래에 아이콘.

## 전투 (요약)

- 판 위 (체스판 원근). 카메라가 돌며 시작, 싸우는 무리를 따라 확대
- 공격: 준비 (머리 위 "!") → 타격. 판정: 회피 → 막기 → 치명타 (x3) → 방어력 (감소율 = 방어력 ÷ (방어력 + 30))
- 방어 (X 누르고 있기): 막기율로 막으면 방패 60% · 맨몸 30% 감소. 맞기 직전에 누르면 저스트 방어 (피해 0, 가끔 반격)
- 회피 (Z): 짧은 스텝. 맞기 직전이면 저스트 회피 (가끔 역전의 기회)
- 출혈 · 감전 · 휘청 (무게로 버팀) · 넉백
- 지휘 (던전 전투): 동료를 누르고 → 칸이면 "버텨", 적이면 "노려". 한 전투에 4번, 인주가 쓰러지거나 휘청이면 끊김
- 🤖 자동 / 🎮 직접 · 속도 x1 / x2 / x4: 전투 위쪽 버튼 (다음 전투에도 그대로)
