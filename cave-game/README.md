# 굴의 프롤로그 (cave-game)

현재 버전: v1.1

## 구성

- `index.html` — 게임 전체 (한 파일). 그대로 브라우저로 열어도 되고, 아티팩트로도 게시됨.

## 지금까지의 구상

### 프롤로그: 노말모드

1. 캐릭터 커스터마이징 (텍스트)
   - 이름 → 성별 → 종족 → 직업 → 머리색(여자만) → 옷 색 → 한마디
   - 여자: 단발머리 / 남자: 대머리
   - 종족: 인간, 고블린, 엘프, 드워프 (체구와 피부색, 귀, 수염이 달라짐)
   - 직업에 따라 시작 무기가 달라짐 (기사 롱소드, 광부 곡괭이, 마법사 지팡이, 도적 단검)
   - 브라우저에 저장되고, 다음에 열면 이어서 할지 물어봄
2. 굴 (로비)
   - 2D 횡스크롤에 3D 느낌을 준 비스듬한 바닥
   - 모든 맵 공통 규칙: 세로 5칸 × 가로로 맵 길이 (로비는 30칸)
   - 폰(캐릭터)은 림월드처럼 단색 도형 + 굵은 외곽선으로 조합

### 등장인물과 자유 행동

| 이름 | 생김새 | 하는 일 |
|---|---|---|
| 레베카 | 루비색 장발, 판금 갑옷의 기사. 벽에 박혀 엉덩이와 다리만 나옴 | 계속 꿈틀댐. 가끔 "읍!" |
| 카리우스 | 3m 거구의 실험체(E-07). 다리 여섯, 팔 넷, 대머리, 둥근 안경 | 모닥불 곁 휴식 → 명상 → 어슬렁거림을 반복. 교대 시간엔 석문을 팜 (머리 위 곡괭이 아이콘) |
| 청광묵 | 작은 체구의 고블린 소녀. 양갈래, 큰 귀 | 석문을 계속 곡괭이질. 교대 시간엔 모닥불 곁에서 쉼 |

- 교대 주기: 청광묵 40초 팜 → 카리우스 24초 팜 → 반복
- 상단 캐릭터 바(림월드식)에 각자 지금 하는 일이 표시됨

## 조작

- 이동: 방향키 또는 WASD (모바일은 화면 패드)
- 말걸기 / 대사 넘기기: Space, Enter, E
- 장비창: I
- 닫기: Esc
