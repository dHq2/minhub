# 굴의 프롤로그 — 구상 노트

문서 버전: v1.1

아직 게임에 들어가지 않은 방향과 설정을 모아두는 곳. 구현된 내용은 README.md에 있음.
확정이 아니라 토론 중인 내용. 바뀌면 여기서 고치고 아래 변경 기록에 남김.

## 1. 게임 방향 (2026-09-29 토론)

- 전술과 전략으로 싸우는 게임. 호쾌한 슬래시가 아님
- 컨트롤만으로 50층까지 깰 수 있는 철권식 게임이기도 함
  - 운은 전략 (길, 보상, 인카운터)에, 전투는 배우면 이길 수 있게
  - 적에게 고정된 패턴과 예고. 천벌처럼 피할 수 없는 것은 대처 (누가 맞을지 고르기)로 풀 수 있게
- 길을 골라 전진, 깨면 보상, 다양한 맵과 인카운터. 돌아오는 로비에서 영웅들과 상호작용
- 50층 = 10층씩 5막 (제안), 막마다 보스
- 화면: 평소 (로비 등)는 공간감 있는 2D 횡스크롤, 전투 때만 3D 느낌 (v10.0 보드 시점이 이 구조)

## 2. 아군

- 아군 약 5명, 영구 사망
- 주인공: 유일한 변화형 영웅. 런마다 무엇이 될지 모름. 지휘는 늘 가능
- 영웅: 정해진 누군가. 몸은 타고나고, 기술은 살아남을수록 늘어남
- 몸 (고정): 체력, 무게, 속도, 특성
- 능력 (성장) 후보: 지휘, 공격, 사격, 방어, 감각 (반응 · 회피), 치유. 담력은 능력으로 둘지 성격으로 둘지 미정
- 경지: 보통의 존재 < 인간의 경지 (포렌. 희귀할 뿐 노력으로 닿을 수 있음) < 경지 너머 (적뢰 등). 경지 너머는 혼자서는 못 이김 → 동료와 전술이 필요한 이유

## 3. 지휘와 명령

- 지휘관을 고를 수 있음. 지휘 가능한 캐릭터가 따로 있고, 주인공은 무조건 가능, 몇몇은 불가
- 명령 후보: 달려가 · 노려 · 버텨
- 명령이 먹히는지 = 들렸나 × 따르나
  - 들렸나: 지휘관과의 거리, 전투 소음. 못 들으면 "?"
  - 따르나: 그 지휘관과의 관계. 싫은 상대면 무시
- 지휘관이 경직되거나 쓰러지면 지휘가 끊김 (포렌 쥐 방패의 "지휘 끊김"을 공통 규칙으로)

## 4. 진형 · 편대 · 인연

- 플레이어가 진형을 배치. 진형에 따라 버프와 행동 양식이 달라짐
- 선호 진형이 있고, 가장 좋은 진형이 따로 있음 (적에 따라 상성)
- 10명이 이루는 진형, 3명이 이루는 삼각편대
- 특정 인연에 따른 특이 조합

## 5. 전직

- 캐릭터마다 두 갈래 (볼륨이 커지는 건 감수)
  - 노먼: 닥터 노먼 / 돌격대 노먼 (방패 착용 가능)
  - 포렌: 쥐를 강화하는 쪽 / 쥐가 본인을 강화하는 쪽
  - 레베카: 선봉대 레베카 / 영웅 레베카
- 장비 그림: 투구 등은 스프라이트 위에 오버레이 (옆모습 · 앞모습), 어색한 캐릭터만 전용 조정. 갑옷은 새로 그려야 할 가능성이 큼

## 6. 로비 방문자 · 인카운터

- 15층 돌파 시 세력의 사절 방문: "몇천 년 만에 15개의 미궁을 돌파한 건 당신이 처음이다. 당신의 여정을 굴이 주목하고 있습니다." 스페셜 5성 2명 중 1명 선택
- 가끔 상인도 찾아옴

### 인물 (이름만 먼저)

- "항해자" 마틴
- "망명자" 허드슨
- "여행자" 오 닐 & 칼

### 토끼마차 1호점

- 주인 아이텐: 인카운터로 출현. 게임 안 재화 등을 팜. 올 때 흑룡도 같이 딸려옴 (로비 상점과 동일)
- 흑룡: 조수. 용인 여자아이. 상시로 코스튬 / 유료 재화를 팜, 가끔 이벤트로 출현
- 청갑: 동업자 겸 보디가드
- 아이텐의 상단도 굴에 떨어졌지만 언제든 돌아갈 수 있음. 그들의 지옥은 이곳이 아니기 때문
- 시련 상태: 흑룡은 시련 중. 아이텐과 청갑은 아직 시련이 끝나지 않음
- 아이텐의 말로는 굴의 "관리자" 중 한 명과 실제로 인연이 있음 (호텔의 관리자 북극곰, 항해자 마틴, 관리자 왕자와 얽힌 인연)

### 파는 물건: 용병 파견

- 어떤 호텔의 투숙객들. 대부분 자기 차원의 시련을 마친 자들 (원래 구상한 원 세계관 쪽 인물들)
- "영웅" 안톤
- "대마법사" 앤서니
- "청소부" 교라 = <악몽:역병>
- <악몽:매화> (누구인지 미정)
- 악몽의 개념은 나중에 다룸

### 파는 물건: 청갑기사단의 펜던트

- 캠페인당 1회 구매 · 사용 가능, 사용하면 파괴. 이벤트 인카운터로 한 번 더 얻을 수 있음
- 청갑기사단 장비도 있음
- 사용 시 청갑기사단 소환: 50 대 50으로 흑룡 또는 청갑 중 한 명이 나옴
  - 살아남은 청갑기사단 단원은 흑룡과 청갑뿐
  - 원래 청갑이 유일한 생존자였는데, 어린 흑룡이 시련 과정에서 청갑에게 정식으로 인정받아 그녀도 정식 청갑기사단
