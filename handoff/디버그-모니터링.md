# 세희 디버그·모니터링 — 보스 계정 상황 보는 법 v1.0.1 (2026-11-14, A)

보스가 "내 계정 접속해서 상황 확인해봐" 하면 이 순서로 본다. 세 방 공통.

## 0. 지켜야 할 것
- 보는 것만 한다. 앱 안 데이터를 고치거나 세희에게 말을 보내지 않는다(보스가 시킨 경우 빼고).
- PIN 을 넣거나 로그인하지 않는다. 계정 서버는 한 번에 기기 하나만 로그인된다 — 다른 데서 로그인하면 보스 폰이 튕긴다.
- 읽은 개인 내용(사람 기록·대화)은 진단에 필요한 만큼만 쓰고, 저장소·문서에 옮겨 적지 않는다.
- 작업 공간(셸)에서는 계정 서버·GitHub Pages 에 직접 못 닿는다(허용 목록 밖). 그래서 보스 브라우저를 빌린다.

## 1. 지금 되는 방법 — 보스 크롬(Claude in Chrome)으로 앱 열기
보스 컴퓨터 크롬에 세희가 이미 로그인돼 있어야 한다(학원 데스크탑 크롬 = 보스가 쓰는 기기).
1. tabs_context_mcp(createIfEmpty) → 새 탭 → https://dhq2.github.io/minhub/sehee/ 로 이동 → 스크린샷 한 장(버전·로그인 상태).
2. javascript_tool 로 상태 읽기(읽기 전용). 자주 쓰는 한 줄들:
   - 판: `({ today:S.today, ver:S.pan.ver, vers:(S.pan.vers||[]).map(v=>v.label), items:S.pan.items.length, open:S.pan.items.filter(i=>!i.done).length, line:S.pan.line })`
   - 대화 끝: `O.log.slice(-12).map(m => m.who + (m.err?'!':'') + ':' + String(m.text||'').slice(0,120))`
   - 사람: `await pplLoad(); ({ people:PPL.list.length, ties:PPL.ties.length, stat:PPL.list.filter(p=>p.stat).length })`
   - 오류: `DBG.lines.filter(l => /오류|실패|error/i.test(l.m)).slice(-10)`
   - 세희 머리: `({ model:AI.cfg.model, busy:O.busy })`
   - AI 호출 기록: `(await kvGet('ailog') || []).slice(-10)`
3. 결과에서 버전 문자열이 '[BLOCKED…]'로 가려지면 `s.includes("v1.5.20")` 처럼 참/거짓으로 묻는다.
4. 올린 새 버전이 실제 주소에 떴는지 볼 땐 앱 밖 페이지에서(https://dhq2.github.io/minhub/ 로 이동한 뒤) fetch 로 index.html·js 를 읽는다 — 앱 안(sehee/ 아래)에서 fetch 하면 서비스 워커가 옛 캐시를 돌려줘서 늘 옛 버전으로 보인다.
5. 다 보면 연 탭을 닫는다.
- 한계: 보스 컴퓨터·크롬이 켜져 있고 확장이 연결돼 있어야 한다(밤·주말엔 자주 꺼짐). 폰에서만 일어난 일은 폰이 서버에 올린 뒤에야 보인다. 폰의 개발자 로그는 폰에서 「개발자 로그」를 켜야 서버로 올라온다(10초마다 마지막 300줄, kv 'dbg').

## 2. 추천 — 개발자 전용 실시간 로그 창 (아직 안 만듦, 보스 승인 기다림)
비교:
| | 지금 방법(1) | 실시간 로그 창(2) |
| --- | --- | --- |
| 폰에서 일어난 일 | 서버에 올라온 것만, 앱을 통째로 열어 봐야 함 | 폰 로그가 10초 안에 그대로 흘러옴 |
| 로그인 | 보스 크롬에 앱 로그인 필요 | 로그인 없음(개발자 열쇠로 읽기만) — 폰 안 튕김 |
| 보스 직접 보기 | 앱을 열어도 로그는 「로그」 탭뿐 | 컴퓨터에서 폰 로그를 실시간으로 |
| 준비 | 없음 | 계정 서버 v3 배포 1번 + 개발자 열쇠 1개(보스가 Cloudflare 에) |
구성(2):
- 앱: 「개발자 로그」를 켠 기기는 10초마다 dbg 와 함께 짧은 상태표(버전·화면·바쁜지·지금 판·사람 수·마지막 오류 — 대화·사람 내용 없음)를 올린다.
- 계정 서버 v3: GET /dev/live — 'x-dev-key' 가 Cloudflare 비밀값 DEVKEY 와 같을 때만, 그 계정의 dbg·상태표만 읽어 준다(쓰기 없음, PIN 과 별개).
- 창: sehee/dev.html — 처음 한 번 열쇠를 넣으면 그 브라우저에만 저장, 5초마다 새 줄을 받아 흘려 보여 줌(분류 거르기·멈춤·「Claude 에게 줄 요약 복사」).
- Claude 방은 보스 크롬에서 dev.html 을 열어 get_page_text 로 읽는다 — 앱 로그인 없이, 폰이 쓰는 중에도.
- 열쇠는 저장소·문서·채팅에 절대 적지 않는다(보스가 Cloudflare 와 자기 브라우저에만).
