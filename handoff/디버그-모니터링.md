3. 폰에서만 보이는 모양(키보드·노치·글꼴 크기)은 보스에게 폰 스크린샷 한 장을 부탁한다.

## 블랙박스·관전석이 하는 일 (v1.5.21 앱 · 계정 서버 v3)
- 앱: dlog 줄을 계정 서버 POST /log 로 새 줄만(쓰는 중 15초, 조용하면 2분, 앱 내릴 때). 줄 = { n, t, c(분류), m(요약), d(원문·자료) }. 대화는 d 에 원문 통째로. 「누름」 줄은 단추 이름·#id. 암호 화면·입력칸은 안 적음. 상태(버전·화면·판·사람 수·마지막 오류·화면 크기)는 바뀔 때만.
- 기기 이름 = 「기기 이름 #짧은번호」(이 기기 localStorage sehee.devid). 관전석은 「… · 관전석」.
- 설정 「개발 기록 남김」 켬/끔(기본 켬). 서버의 LOG_USERS 에 없는 계정은 서버가 안 받고 앱도 바로 멈춤 — 다른 사용자에겐 아무 일 없음.
- 계정 서버 v3: 표 logs·devstate·logcursor·observers. GET /log(본인 계정만). 크론 5분: 안 보낸 줄을 계정마다 최대 400줄씩 금고에 새 파일로(덮어쓰기 없음). 한 시간에 한 번: D1 은 금고로 간 3일 지난 줄 지움, 금고는 30일 지난 날짜 폴더 지움, 30일 지난 관전석 표 지움.
- 관전석: 로그인 몸통에 observe:true → observers 표에 따로 기록(current 안 건드림 → 폰 안 튕김). 서버가 /data 쓰기 403. 앱은 올리기·세희 부르기 막음, 위에 띠 + 나가기.
- D1 무료 한도(하루 쓰기 10만 줄): 줄 하나 = 넣기 1 + 지우기 1. 하루 종일 바쁘게 써도 수만 줄 — 한도 안. 넘치면 앱은 계속 되고 로그만 그날 멈춘다(UTC 0시 = 한국 9시 초기화).

## 보스가 한 번 해 둘 것 (준비)
1. GitHub 에 비공개 저장소 하나(예: 「sehee-logs」, README 하나 넣고 만들기).
2. GitHub 설정 → Developer settings → Personal access tokens → Fine-grained tokens → 새로 만들기: Repository access = 그 저장소 하나만, Permissions → Contents = Read and write, 만료는 원하는 만큼. 토큰은 복사해서 바로 3번에만 붙인다(채팅·저장소에 적지 않기).
3. Cloudflare → Workers → sehee-sync:
   - 코드 편집 → 저장소의 sehee-sync/worker.js(v3) 전체를 붙여 넣고 배포.
   - 설정 → 변수 및 비밀: LOG_USERS = 보스 계정 이름(텍스트), GH_REPO = 「GitHub아이디/sehee-logs」(텍스트), GH_TOKEN = 2번 토큰(비밀).
   - 설정 → 트리거 → 크론 트리거 추가: */5 * * * *  (5분마다)
4. 집 데스크탑 크롬에서 https://dhq2.github.io/minhub/sehee/?watch=1 → 「보기 전용」 체크된 채로 암호 → 띠가 뜨면 끝. 그 탭은 열어 둔다.
5. Claude 방에 저장소 이름만 알려 준다 → 방이 add_repo 로 붙인다(읽기만).
- 확인: https://(계정 서버 주소)/ 를 열면 { v:3, logs:true, vault:true } 가 보이면 된다.
