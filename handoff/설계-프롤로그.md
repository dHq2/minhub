# 세희 처음 켤 때 프롤로그 — 설계 v1.0 (2026-11-15, A)

보스 요청(11-15 02:20): 「초반 세팅 프롤로그 — 나를 누구로 부를지, 간단한 업무 설명, 나의 프로필 쓰기」.
B 가 만드는 장면 틀(js/scene.js — 화면 어둡게·세희 스탠딩·대화창·선택지·입력칸)이 올라오면 그 위에 얹는다. 같은 모양을 두 번 만들지 않는다.

## 언제 뜨나
- 이 계정(또는 「이 기기만」 기기)에서 한 번도 안 한 경우: kv 'intro' 가 없고, 판·대화·인간관계가 비어 있을 때.
- 이미 쓰던 사람(보스 계정 등)은 안 뜬다. 설정에 「처음 인사 다시 보기」 단추.
- 가입 직후(새 계정) → 사무실 화면이 처음 그려진 다음.

## 순서 (대사는 세희 말투, 보편 설계 — 직장·학원 단어 없이)
1. 인사: 「처음 뵙겠습니다. 오늘부터 곁에서 일을 도와드릴 비서, 강세희예요.」
2. 호칭: 「제가 뭐라고 불러 드리면 될까요?」 — 선택지 [보스] [사장님] [○○님(이름으로)] [직접 쓰기]. ○○님을 고르면 이름을 묻는다.
3. 하는 일: 「요즘 주로 어떤 일을 하세요? 한 줄이면 충분해요.」 — 입력칸 + 예시(가게 운영, 회사 일, 공부, 육아…) + [나중에].
4. 프로필: 「제가 알아 두면 좋은 게 있을까요? 일하는 시간, 자주 연락하는 사람, 싫어하는 것 같은 거요.」 — 여러 줄 입력 + [나중에].
5. 짧은 안내(3장면): 왼쪽 일간보고서 / 오른쪽 견출지(달력·보드·사람) / 아래 말 걸기 — 「일은 판에, 사람은 인간관계 판에 적어 둘게요. 아무거나 말로 던져 주세요.」
6. 마무리: 「그럼 ○○, 오늘 할 일부터 같이 정리해 볼까요?」 → 대화창 닫고 사무실.

## 저장
- 호칭 → AI 설정(cfg.callMe). 세희 지침 첫 줄 「사용자를 '보스'라고 부른다」를 cfg.callMe 로(없으면 '보스'). — js/ai.js 한 줄.
- 이름·하는 일·프로필 → 인간관계 판 「나」 카드(PPL.me: name, role, extra[] 에 [stated] 처럼 한 줄씩). 세희가 앞으로 이 카드를 보고 맞춘다.
- kv 'intro' = { at, v:1 } — 다 했거나 건너뜀. 동기화 대상(다른 기기에서 다시 안 뜨게).
- 개발 블랙박스: dlog('화면', '프롤로그 n단계') 와 고른 값.

## 나눌 일
- B: scene.js 에 「입력칸(한 줄·여러 줄)」과 「건너뛰기」가 있으면 그대로 씀. 없으면 A 가 scene.js 에 작은 함수 하나 더하자고 from-a 로 부탁.
- A: js/intro.js(새 — 순서·저장), ai.js 호칭 한 줄, settings 「처음 인사 다시 보기」, tests/tintro.js.
