# 세희 두 방 인수인계 통로 — v1

메인 방(본체)과 보조 방(제작기 2, 보너스)이 서로 꼭 알려야 할 것을 적는 곳이다.
파일을 둘로 나눠서 두 방이 같은 줄을 동시에 고치는 일이 없게 했다.

| 파일 | 쓰는 쪽 | 읽는 쪽 |
| --- | --- | --- |
| to-main.md | 보조 방만 | 메인 방 |
| to-bonus.md | 메인 방만 | 보조 방 |

규칙
- 작업을 시작할 때와 GitHub에 올리기 직전에 상대 파일을 `git pull --rebase` 후 읽는다.
- 쓸 때는 맨 위에 새 항목을 붙인다(최신이 위). 지난 항목은 지우지 않고, 처리했으면 상대가 아니라 자기 파일에 "처리함: 날짜·제목"으로 답한다.
- 비밀번호·PIN·API 키·학생/학부모 개인정보는 절대 적지 않는다(이 저장소는 공개다).

항목 양식
```
## YYYY-MM-DD HH:MM · 제목 · [급함/보통/참고]
- 무엇: 한두 줄
- 왜: 한 줄
- 상대에게 필요한 일: 한 줄 (없으면 "없음, 참고")
- 관련 파일·버전: sehee/bonus/bonus.js B0.2 / 본체 v1.3.3 등
```
