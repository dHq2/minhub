# 굴의 도감

현재 버전: v1.22

굴의 프롤로그에 들어갈, 지금까지 받은 그림을 분류별로 모아 둔 페이지. 게임에서 쓰지는 않음 (정리용).

- `index.html` — 도감 화면 (분류 탭 · 체크 · 메모 · 체크 목록 복사 · 백업 저장 / 불러오기)
- `catalog.js` — 항목 목록. 항목마다 바뀌지 않는 번호 (R01, EW03, C12 …). 체크 · 메모는 이 번호에 붙음
- `pack/` · `packs.js` — 작은 그림을 합친 묶음과 자리표 (`tools/pack.py`가 만듦)
- `img/` — 받은 그림을 잘라 줄인 가공본 (webp). 원본은 저장소에 두지 않음
- `a` → `../cave-game/assets` (게임에서 이미 쓰는 그림)

분류: 1 유물 (청록 바탕) · 2 장비 (보스 등급은 핏빛 바탕) · 4 컷씬 · 5 배경 · 6 카드 · 인카운터 · 스킬 등 · 7 동작 (움직이는 그림) · 8 인물 · 9 2D판 인물 · 10 표정 · 11 가구 · 소품

체크와 메모는 도감 페이지의 저장소 (db, `marks` 모음)에 들어가 Claude가 바로 읽을 수 있음. 백업 저장은 같은 내용을 .json 파일로 내려받음.
