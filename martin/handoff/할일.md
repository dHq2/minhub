# 마틴 할 일 목록 — v1 (2026-11-16)
네 방(A·B·C·D) 모두 쓴다. 자기가 맡은 줄과 새 줄만 고친다. 찜 = '맡음:' 에 내 방, '파일:' 에 고칠 파일을 적고 바로 올리기(push). 끝나면 [x] 로 바꾸고 맨 아래 '끝난 일'로.
양식: `- [ ] 일감 · 맡음: 없음/A/B/C/D · 파일: … · 보스 요청: 날짜 · 메모`
같은 파일을 남이 맡고 있으면 시작하지 않고, 함수 단위로 나누거나 보스에게 묻는다.
