# 굴 전투판 설계서 v1

- 대상: `battle/index.html` (모바일·PC 겸용 브라우저 게임, 빌드 없음)
- 근거: 사용자 스케치 2장, `gul_logic_v3_claude_handoff.md`(굴 로직 검토 메모), 질의응답 5회
- 주의: 굴 청사진(`gul_blueprint_v1.0.md`)이 없어 수치는 이 문서의 단순화 값. 엔진 수치는 모두 `js/data.js`, `js/sim.js` 상단에 모여 있어 조정이 쉽다.

## 1. 목표

굴 도감 전투판을 단순화한 시뮬레이션. 전투를 단순하게 완성하고, 성장을 완성하기 위한 판.
멈추고 계획을 짜고, 실시간으로 지휘 상황을 보며 진행한다. 적 AI는 강해야 하고, 장차 PVP로 확장한다(그래서 양쪽이 같은 규칙과 같은 명령 API를 쓴다).

## 2. 확정된 결정

- 화면: 하얀 개활지 64m x 40m (1칸 = 1m). 횃불·시야 없음(정보 완전 공개). 세로 화면에서는 맵이 세로로 회전해 아군이 아래쪽.
- 색: 흰색 = 아군, 검정 = 적.
- 병종(모양): 네모 방어(느리고 튼튼한 탱커), 동그라미 보병(균형), 세모 기동(빠르고 체력 낮음), 오각형 사수(사격 스탯 최소치 보장).
- 무기: 맨손, 둔기, 검, 창, 포, 방패. 병종과 무기는 자유 조합. 포 외의 무기는 방패를 함께 들 수 있다.
- 시작: 보병1, 보병2, 탱커1, 사수1 (4인). 적도 4인에서 시작.
- 한 판: 보유 인원 전원 출전, 적은 보유 인원 + (5단계부터 +1, 10단계부터 +2). 전멸 승리, 시간 제한 없음(안전 종료 20분, 교착 시 무승부).
- 성장: 승리할 때마다 랜덤 유닛(병종·무기·스탯 모두 랜덤) 1명 합류. 쓰러진 유닛은 영구 손실. 아군 전멸 시 런 종료, 새 런은 4인으로 시작. 보유 최대 12명.
- 계급: 이병 → 일병(생존 승리 2회) → 상병(4) → 병장(7) → 하사(11) → 중사(16) → 상사(22). 승급 때마다 강화 3택1(스탯, 전직(병종 변경), 재무장(무기 변경)). 계급은 지휘 스탯 +3씩.
- 준비 단계: 전투 개시 전에는 시간이 멈춘 채 배치(끌어서), 지휘관/분대장 임명, 분대 편성, 명령을 미리 내릴 수 있다.
- 로그: 매 판 이벤트 로그(타격·막기·사격·돌격·명령 전달 경로·승계)를 브라우저에 자동 저장(최근 25판)하고 JSON/TXT로 내보낸다. 런 상태도 자동 저장.

## 3. 지휘 체계

- 총지휘관(★): 처음엔 지휘 스탯 최상 유닛. 분대가 하나라도 생기면 ★★. 유저가 임명할 수 있다.
- 분대장(★): 진형 그룹(분대)을 편성하면 자동 생성(계급 → 지휘 스탯 순 최선임). 유저가 임명할 수 있다.
- 유사시 승계: 총지휘관 사망 시 가장 가까운 분대장, 없으면 최선임. 승계 직후 2초 동안 전달이 느려진다. 분대장 사망 시 분대 내 최선임.
- 명령 전달: 총지휘관의 명령은 목표 유닛과 그 분대장에게 동시에 간다.
  - 직접: 거리 비례 지연(기본 0.15s + 거리/16m/s, 지휘 스탯이 높을수록 빠름). 거리와 근접 적(소음)에 따라 전달 실패, 실패하면 1.5초 뒤 2차 전송(실패율 절반).
  - 분대장 경유: 총지휘관 → 분대장 → 부하. 분대장 근처(지휘 범위의 35% 이내)에서는 사실상 실패하지 않아 직접 전달보다 빠르고 확실할 수 있다.
  - 먼저 도착한 쪽이 적용, 뒤늦게 도착한 중복은 무시.
  - 지휘 스탯(5~99, 랜덤)이 전달 속도·정확도·범위를 함께 결정. 지휘 범위 = 6m + 0.12m x 스탯.
  - 화면: "…" = 전달 중, "✗" = 전달 실패, 점선+점 = 신호 이동(청록 직접, 주황 분대장 경유).
- 우선 명령: 같은 곳을 빠르게 두 번 탭(더블클릭). 기존 명령을 보류하고 즉시 수행, 끝나면 원래 명령 재개(최대 3중 보류).
- 진형: 분대 전원을 선택해 이동하면 분대의 상대 위치(진형)를 유지. 임의로 여러 명을 선택해도 현재 간격을 유지하며 이동(가장 느린 유닛 기준 속도).

## 4. 전투 규칙 (굴 로직 반영 범위)

반영한 것
- 막기와 방패 방향: 막기는 정면 부채꼴(무기 50~80°, 방패 150°)에서만 성립. 옆·뒤(약 115° 밖)는 막지 못하고 배후 피해 x1.35. 방패는 흡수 80%, 무기 막기는 50%.
- 방어 태세: 막기 +15%(사격 막기 +10%), 균형 저항 x1.6, 밀림 저항, 돌격 피해/균형/밀림 감소, 이동 35%, 스태미나 회복 절반, 적극 추격 없이 반격만. 창은 방어 태세에서 돌격하는 적에게 대기창 반격.
- 스태미나·피로: 공격·막기·돌격이 소모, 낮으면 이동·공격 약화, 막기 중 바닥나면 막기 붕괴(경직).
- 돌격: 공격 돌격(창 찌르기 x1.8, 검·둔기 휘두르기 x1.5), 몸통·방패 돌격(질량 x 속도 충돌). 충돌 피해·밀림·반동. 방패를 든 창 돌격은 밀림 보너스.
- 전열 버팀: 충격이 향하는 쪽 뒤에 붙은 아군(최대 3)이 질량·균형 저항을 보태 준다.
- 넘어짐/경직: 균형이 0이 되면 넘어짐(1.6초, 피해 x1.25), 막히지 않은 중타는 경직. 넘어진 적은 AI가 우선 노린다.
- 사선·오사: 사격은 직선 투사체. 경로상 처음 닿는 몸이 맞는다(아군 포함). 사수는 시작·발사 순간 사선을 점검하고 막히면 옆으로 비킨다. 포는 작은 폭발(반경 0.8m)이라 가까운 아군도 피해.
- 사격 스탯: 사수는 최소 55 보장, 보병·기동병은 키워야 한다. 명중률은 사격 스탯·거리·표적 속도로 결정.

이번에 뺀 것(v1.1 이후 후보)
- 스텝·도약·공중제비, 은신·포복·암살(시야가 없는 판이라 제외), 의식상실·호송·치료, 횃불, 단검/장검 무기 변형, 막기 정책(guardMode 3종, 요청으로 제외).

## 5. 적 AI

플레이어와 동일 규칙: 별·분대장·전달 지연/실패를 그대로 받는다(정보만 완전 공개).
- 준비: 총지휘관 임명(가급적 최전열 방어병 제외), 전열/기동대/사수 분대 편성.
- 전열: 분대 진형으로 전진 → 접촉하면 집중 목표(사수·부상·쓰러진 자·지휘관)를 골라 공격. 방패병은 돌격이 다가오면 방어 태세. 창병은 방비 없는 상대에게 돌격.
- 기동대: 측면에서 대기 → 전열 접촉 후 적 측면을 돌아 후방의 사수·지휘관에게 돌격.
- 사수: 집중 목표 우선, 아군 근처 폭발 위험 회피, 접근하는 적과 거리 유지(후퇴).
- 부상(HP 25% 미만)·탈진은 이탈 후 예비. 25초간 아무도 피해를 못 주면 전원 추격(교착 방지).
- 헤드리스 검증(60판): 같은 편성 대칭 대결 34:25(처리 순서 편향 제거 후), 돌진만 하는 상대에겐 60:0.

## 6. 난이도 설계 메모

- 적 스탯: 같은 생성 규칙. 단계당 성장(체력 +3.6, 공격 +2.2%, 방어 +0.2). 1~8단계는 완화 계수 0.72 → 1.0(체력·공격).
- AI끼리 캠페인 시뮬레이션: 평균 약 4단계 도달, 승리 판에서 평균 1명 손실. 사람이 직접 지휘하면 더 나아가는 것을 기대. 로그로 조정할 예정.

## 7. 조작

- 선택: 유닛 탭, 상단 칩 탭, 빈 땅 끌어 박스 선택, "다중 선택" 토글.
- 땅 탭 = 이동(교전 포함), 적 탭 = 공격. "돌격"/"이탈" 버튼 후 탭. "정지 사수", "방어 태세", "명령 취소".
- "경유 +": 땅을 여러 번 탭해 우회 경로를 만들고 다시 눌러 전송.
- 분대 편성/해제/선택, 분대장 임명, 지휘관 임명. "AI 맡김": AI 지휘관에게 아군을 맡김.
- 시간: 정지/재개(스페이스), 1x/2x/4x. 확대: 핀치·휠, 이동: 두 손가락·가운데/오른쪽 버튼, "맞춤".
- 준비 단계: 유닛을 끌어 배치(자기 진영 구역 안).

## 8. 파일 구조

```
battle/
  index.html            화면·스타일
  js/core.js            상수, 난수(시드), 유틸
  js/data.js            병종·무기·계급, 스탯 계산, 랜덤 유닛 생성
  js/log.js             이벤트 로그, 저장(localStorage), 내보내기
  js/command.js         지휘망(별·분대·전달 지연/실패·승계)
  js/sim.js             전투 시뮬레이션(이동·공격·막기·돌격·사격)
  js/ai.js              적 지휘관 AI (+ 비교용 기준 AI)
  js/run.js             런(단계·보상·영구 손실·승급)
  js/ui.js              렌더·입력·화면
  js/main.js            부팅
  tools/headless_v1.js  헤드리스 검증(결정론, AI 대결)
  docs/battle_design_v1.md  이 문서
```

- 일반 `<script>` 태그로 불러오므로 파일을 그냥 열어도(file://) 동작. 서버·빌드 불필요.
- 시뮬레이션은 고정 틱(0.05s)·시드 난수·명령 기록만으로 진행되는 결정론 구조(PVP·리플레이 대비).
- 저장 키: `minhub.battle.v1.run`, `minhub.battle.v1.logs`.

검증 명령
```
node battle/tools/headless_v1.js 60 sym        # 같은 편성 대칭 AI 대결
node battle/tools/headless_v1.js 60 vsrush     # AI 대 돌진
node battle/tools/headless_v1.js 1 det         # 결정론 검사
```

## 9. 알려진 한계 / 다음 후보

- 밸런스 수치는 시뮬레이션 기반 1차값. 실제 플레이 로그로 조정 필요.
- 항복 외에 전투 중 막사 복귀 불가(재시도 악용 방지). 새로고침하면 같은 판이 같은 시드로 다시 시작되는 점은 허용.
- 계급은 지휘 스탯과 승급 강화에만 연결. 계급에 따른 분대장·지휘관 자동 선정은 임명 없을 때 최선임 기준으로만 동작.
- v1.1 후보: 리플레이 재생(시드+명령 기록 이미 저장), PVP 연결, 도약·스텝, 암살, 의식상실·호송, 계급제 확장.
