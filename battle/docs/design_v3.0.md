# 전투판 설계 v3.0

## 한 줄 요약
굴 원본 엔진(vendor/gul)을 수정 없이 얹고, 그 위에 흑백 격자 전술 게임(성장·루팅·캠페인·UI)을 얹은 구조.

## 변경 기록
- v3.0.0: 원본 엔진 도입으로 전면 재작성. v1/v2 자체 구현 폐기.
- v3.0.1: 핀치 시 ReferenceError(view 미정의) 수정. 자동 카메라 도입 후 점검.
- v3.0.2: Artifact 뷰어용 로그 저장을 downloads 기능으로 연결(없으면 기존 링크 방식). tools/make_artifact.py 추가.

## 구조
- vendor/gul: 원본 엔진 사본. 수정 금지. UPSTREAM.md 에 커밋 해시.
- tools/patches: 엔진을 바꿔야 할 때만 빌드 시점 패치로(현재 없음).
- tools/engine_exports.txt: 엔진 내부 함수 중 우리가 쓰는 것을 module.exports 에 덧붙임.
- src/manifest.txt 순서로 core → game → ui 를 이어 붙여 dist/battle.html 한 파일로 만듦.
  - core: 엔진 어댑터(rules, designs, battle, orders). 엔진 접근은 GB.E 로만.
  - game: 성장, 전리품, 캠페인, 저장, 판 로그.
  - ui: view(캔버스), input(탭·끌기·핀치), panels, screens, main.

## 게임 규칙 요약
- 시작: 보병1(의무 응급처치), 보병2(보병1과 전우조), 탱커1(지휘), 사수1. 적도 4명.
- 승리하면 랜덤 신규 유닛 1명(병과·무기·체급·능력·의무 스킬 랜덤). 전사자는 영구 손실. 전멸 시 런 종료.
- 보유 최대 20명, 전투는 10~20 vs 10~20, 인원에 따라 맵 자동 확대(36x22 ~ 68x38).
- 체급 소형~초대형. 승리 시 성장(판당 최대 2개 등급 상승).
- 갑옷/투구는 몸 체급과 같거나 한 단계 큰 것만 착용.

## 조작
- 유닛 탭=선택, 땅 탭=이동, 적 탭=공격, 물건 탭=줍기, 같은 곳 다시 탭=서둘러(사수는 즉시 사격)
- 빈 땅 끌기=네모 선택, 준비 단계 아군 끌기=배치, 두 손가락=확대·이동
- PC 키: 스페이스 일시정지, H 정지, G 자동, X 취소, L 횡대, B 방어, A 공격이동, F 돌격, R 투창

## 로그
- 판마다 BattleLog 를 브라우저 저장소에 자동 저장. JSON/TXT 내보내기 지원.
