# 굴 원본 엔진 점검 결과 v1.0

대상: dHq2/minhub gul/ 의 rt3_head/mid/tail.js (v9.10.0, 커밋 2afc35d6916e302293ff8ad396bcf16fea590b86)
방법: 원본 엔진을 수정 없이 그대로 불러와 헤드리스로 4v4 / 10v10 / 20v20 판을 돌리고, 모바일(390폭)·PC 화면으로 실제 플레이 흐름을 눌러 봄.

## 그대로 가져다 쓴 것 (다시 만들지 않음)
- 부위 피해, 출혈, 기어다니기, 치명상, 측면·후방 보정
- 방어구/투구(체급 맞춤), 루팅, 투창, 돌격, 짓밟기(거구), 응급처치
- 전우조, 대장-부하 지휘망(전달 지연 포함), 교전 규칙 태세
- 결정론적 난수, 30Hz 고정 틱

## 부족하거나 우리 목표와 어긋난 곳, 그리고 처리
1. 시야/횃불 — 원본은 시야 개념이 기본. 처리: 규칙값(sight 999, spareTorches 0, amb 1)만 바꿔 제거. 엔진 수정 없음.
2. 제한시간 300초 — 대규모 전투에는 짧음. 처리: tmax 600으로 상향(규칙 오버라이드).
3. 대칭 AI 편향 — 같은 전력으로 붙이면 0번 진영이 약 92% 이김. PvP를 생각하면 공정하지 않음. 처리: 적 전력에 handicap(0.75 + 0.04*(단계-1))을 곱해 단계별로 조절. 근본 해결(진영 대칭화)은 후속 과제.
4. 20v20 성능 — 틱당 약 5.2ms. 모바일에서 프레임 비용이 24ms를 넘으면 배속을 자동으로 낮춤.
5. AI 자동 루팅이 드묾 — 전투 중 아군이 알아서 줍는 일이 거의 없음. 처리: 탭으로 줍기 명령, 승리 후 전리품은 창고로. AI 루팅 정책 패치는 후속 과제.
6. 충돌이 딱딱한 원 — 세포처럼 비비적거리지 않음. 처리: 화면에서만 겹침을 눌러 보이게 하는 squish(엔진 값은 안 건드림).
7. UI 밀도 — 원본 조작은 PC 위주로 촘촘함. 처리: 탭 3개(명령/태세/편성·관계)로 줄이고 자동 카메라 추가.
8. 대규모 전투가 가운데로 몰림 — 전체 지도 줌에서 유닛이 작게 보임. 처리: 자동 추적 카메라(수동 핀치/휠/이동 시 해제, 맞춤 버튼으로 재개).

## 후속 과제
- tools/patches 로 AI 자동 루팅 정책 추가
- 진영 대칭 검증(PvP 대비)
- 질량 가중 분리(비비적 연출을 엔진 쪽으로)
