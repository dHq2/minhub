# 프롤로그: 낙하와 청광묵

문서 버전: v1.0 (2026-10-04)

민수 구술 (2026-10-04)을 장면 순서대로 옮긴 연출 대본. 시간 · 카메라 · 화면 · 조작을 칸으로 나눔. (?) 는 아직 안 정한 곳.

## 0. 원칙

- 화면은 어둡게. 프롤로그 내내 조명은 낮고, 빛나는 건 떨어진 장비뿐
- 맵은 둥글게 (원형 구덩이). 벽 없이 빠져나갈 곳이 없는 느낌
- 튜토리얼 = 청광묵. 이성 없이 돌격만 함. 잡히면 바로 게임 오버 (먹힘)
- 대사는 3초 잠금: 대사가 뜨고 3초 뒤에야 엔터로 넘어감 (천천히 스킵)
- 굴 장면은 약간 몽환적으로. 도감 에셋 (소품 · 바닥 · 가구)을 이어 붙여 바닥 · 벽을 만듦

## 1. 장면 순서

### 1-1. 낙하

- 주인공 (인주)이 돼지 · 시체 · 갑옷 같은 것들과 함께 둥근 구덩이로 떨어짐
- 화면: 어둡게. 떨어진 것들이 바닥에 흩어짐
- 에셋 후보: 돼지 (I-109), 시체 (H-008 피 흘린 시체 · H-023 갑옷 시체 · H-287 쓰러진 시체), 갑옷 (장비 갑옷 아무거나)

### 1-2. 청광묵 등장

- 카메라: 줌인하며 청광묵을 잡음
- 화면: 청광묵 초상화 + 대사창
- 말풍선: "......크아아!!"
- 청광묵이 돌격 시작 → 화면이 전투로 전환

### 1-3. 전투 (튜토리얼)

- 플레이어는 빛나는 장비들을 확인함 (바닥에 떨어진 것 중 몇 개만 빛남)
- 창을 주움 → 여기서부터 조작 시작
- 나레이션 (화면 위 안내 줄):
  - "F키를 눌러 투척할 수 있습니다!"
  - "Q로 회피할 수 있습니다!"
- 청광묵: 이성 없이 돌격만. 잡히면 → 게임 오버 (먹히는 장면으로 끝)

### 1-5. 굴 (스토리 시작)

- 분위기: 약간 몽환적. 바닥 · 벽은 에셋을 이어 붙여 만듦
- 카리우스: 굴을 파는 중. "....." → 말 걸면 "...캉. 캉."
- 청광묵: 눈에 흉터가 남아 있음 (창에 맞은 자리). 인광달팽이를 돌보는 중
  - "대장! 일어났나!" → 여기서 움직이기 가능
  - 달팽이 곁: "아우.... 귀여워!" / "대장! 아직 먹으면 안된다! 알! 낳아야한다!"
- 레베카: 벽면에 머리만 빼꼼, 얼굴이 하늘을 본 채로 박혀 있음. zzz...
  - 말 걸면: "...음냐..음냐..." (자고 있는 모양이다)
- 인광달팽이: 가축. 평소 그림 (P-glowsnail-art). 흥분판 (P-glowsnail-angry)은 나중에

## 2. 필요한 것

### 이미 있음

- 청광묵 원화 · 초상화 (P-goblin-art · F-auto-goblin), 인주 동작 그림, 카리우스, 레베카
- 인광달팽이 평소 · 흥분, 돼지 · 시체 · 갑옷 소품, 창
- 3D 시제품: 투창 (완벽 투창 카메라 포함), 회피, 예고 장판, 카메라 줌

### 새로 필요

- 청광묵 돌격 동작 (지금 시제품에 없음), 무너짐 · 기어감 동작
- 청광묵 눈 흉터판 (굴 장면용)
- 레베카 벽에 박힌 머리 그림
- 카리우스 곡괭이질 동작 (캉캉)
- 인주 주저앉음 동작
- 게임 오버 (먹힘) 장면

### 조작 바꿈

- 지금 시제품: 투창 = 우클릭. 대본: 투척 = F, 회피 = Q. 둘 다 받게 할지 정해야 함

## 3. 열린 질문

- 승리 뒤 마지막 컷신 "청광묵에게 주인공이 창을 ..." 끝부분 (건져? 던져? 꺼내?)
- 청광묵이 머리에 창을 맞고도 살아서 동료가 되는 이유 (나중 이야기로?)
- 게임 오버 뒤: 낙하부터 다시인지, 청광묵 등장부터 다시인지
- 메모의 "실명 저주"와 "청광묵의 외눈" 장면은 이 대본에서 빠짐. 따로 둘지 합칠지
- 초기 낙하물 (어부의 창 / 목걸이 + α): 1-3에서 줍는 창이 어부의 창인지
