# 민수 손메모 정리 (2026-10-04, 노트 5장)

문서 버전: v1.0 (2026-10-04)

손메모 사진 5장을 옮겨 적고 주제별로 묶은 것. (?) 는 글씨가 흐려 확실하지 않은 곳. 확정은 민수가 함.

## 1. 한 줄 요약

- 가챠 = 낙하. 매일 아침 하늘에서 무언가 떨어짐 (적 · 침대 · 장비 · 식량 · 날씨). 뽑기의 정체가 세계 안의 사건
- 하루 단위 굴 생활 + 따로 있는 탐사. 굴에서는 문 부수기 · 무드 관리 · 쓰레기 청소 · 가구 만들기, 탐사는 어둡고 위험한 맵에 공략조 · 정찰조를 보냄
- 별 (★)은 태생 차이일 뿐 전투력 차이가 아님. 실제 힘은 7단계 스킬 등급 (S A B C D E F, 색으로 구분)과 특성
- 첫 보스 적뢰는 "천벌" 예고 → 마지막 준비날 → 폭우 → 강림의 흐름. 이기는 길은 컨트롤뿐
- 버린 것: 운명의 카드 뽑기 (별로), 색을 되찾는 낙오자 컨셉 (세계관 아님), "나는 뭘 해야 하나 / 색을 잃었다" 식의 추상적 내러티브

## 2. 쪽별로 옮겨 적기

### 1쪽: 가챠 · 등급 · 동료 정리

- 페흐토.. 가챠 (인물?) / 이도저도 (?) ... / 다 만들 수 있는 아이디어.. / 페흐토와 연관 유물
- 가챠는 어떻게? / 전선 (?)
- 아이템 종류: 유물 · 장비 · 유물장비 · 보스장비 (보스유물은 지움) · 인카운터 유물 · 인카운터 장비
- 뽑기, 운명의 카드? 카드는 좀 별로인데
- 색이나 낙오자 컨셉? 세계관 아님. 죄?
- 생각해 보기 // 확정 필요. 나머지는 스탯으로?
- 색깔로 구분: S A B C D E F → 총 7단계의 스킬, 웬만해선 C부터 시작
- 특성 분류: ★ 근력 / ★ 발화탄 ~5 (화염 관련) / 축복: 불사 C
- 인주: 나중에 공격 스프라이트 더 필요
- 카리우스: 그대로 구현. 특성: 개조된 신체, 탱커
- ★ 청광묵: 손바닥 발화탄, 점프 펌프 (?). 공용 스킬 이미지 필요
- ★★ 레베카: 좋은 이름 없나? 축복 · 불사 · 재생으로 버티는 몸 (?) → 버티기 탱커
- ★★ 모닝스타: 강한 근력. 철퇴를 빙빙 돌려 머리를 후리고 다리 후리고, 관절을 부숴 버려서 막음. 근접의 천적
- ★5 포렌: 원 설정 그대로, 연출만 살짝 체인지
- ★★ 노먼: 응급치료 호흡 (?) 개선해야.. 사격 C로 시작, 베테랑이니
- 피엘 · 오도 · 돌쇠 · 구르 · 헤론: 삭제. "영구 삭제, 모든 저장소에서"

### 2쪽: 장비 · 별 · 동료 개별

- 동료도 장비를 들게 할까. 갈아 끼우는 건 못해도 내가 주면 (?) 착용. 예를 들어 장신구 · 방어구 계열 스킬은 사용 가능할 듯
- 무기는? 공격 버프만? 그 특수 스킬은 못 쓰게 있는 거지. 주인공만 일단 사용 가능하게?
- 보상으로 획득, 중복 획득
- ★은 태생의 차이일 뿐, 유의미한 전투력 차이라고는 보기 어렵다
- 4★ 용묘화: 상시. 본명 후보를 여러 번 고침 (흐림)
- 4★ 모로: 맵 클리어 보상 시 일정 확률로 출현
- 4★ 고딕 기사: 상시. 본명 락토. 고유 특성 갑피 (?). 근력 / 괴력
  - 갑피: 갑옷을 안 입어도 갑옷 입은 방어 효과
- 이 게임에서 가챠란 뭘까? → 난 그걸 낙하라고 생각했는데
- 1★ 간호사: 본명 튜니. 후방에서 대기하고 뭐처럼 (?) 도약도약 뛰어다님. 기본 치료 스킬 아이콘. 비전투, 주사, 근접만 가능
- 2★ 넬로 (현 옐로, 예전 이름 '예라'는 지움): 도약하기. 롤러스케이트는 의도가 아님. 오히려 수인에 가까움. 전투하는 넬로는 꽤 강함. 괴력 C
  - 강스킬: 얼굴이 검어지고 강하게 3번 휘두름 (원거리 참격처럼)
  - 넬로의 녹은 피부는 약간의 치료와 지혈 효과가 있음
  - 원래는 평범한 간호사, 시간이 없으면 잘 녹음 (?)
- 나는 뭘 해야 하는가? 색을 잃었다? 그런 추상적 중2병 내러티브는 아님
- 차륜 (노랑): 인카운터로만 등장, 비전투
- 마리 & 와킨: 비전투 인원, 4성 정도의 전력. 이벤트로 도움 요청권 획득 가능
- 그림: 뽑기 결과 화면 (10칸)

### 3쪽: NPC · 인카운터 · 맵 · 프롤로그 · 하루

- 노랑고양이: NPC. 악마종 (?). 본명 코라. 이벤트 인카운터로 등장
- 대장군: 중간 보스급. 묵직한 검격 / 타격. 특수 능력 없음
- 퀸 아리안: 강적. 보스도 아닌 주제에 강함. 크게 적대적이진 않음
- 오닐 & 칼: 검은 공간, 한참 걷다 보면 조우. 그들에게 출구를 알려 주면 이벤트 종료. 그러나 그들은 떠나지 않음. 이후 한 번 더 만나면 플레이어의 정신도 (?)나 성향에 따라 선물을 줌. 히든: 현자의 검
- 맵은 어두워야 함. 공략조 & 정찰조. 생환 못 하는 경우도 많아야 함
- 프롤로그: 청광묵이 떨어진 주인공을 보고 달려듦. 이때 청광묵을 잡으며 전투를 끝냄. 초기 낙하물은 어부의 창 / 대지 (?)의 목걸이 + α 고정 (등급 없음)
- 그림: 굴 안 장면 + 오네레이 (?) 말풍선
- 적을 죽일수록 시체는 쌓임! 좋아, 익숙해질 때까지
- 오늘은 무엇을 할까? 아침에 낙하. 문 부수기, 하루에 5시간? 즉, 매일 아침에 문을 파는 게임
- 무드 관리 · 쓰레기 청소 · 가구 만들기! 탐사는 이와 무관한 콘텐츠

### 4쪽: 굴 · 낙하 · 오프닝 · 식량 · 상태창

- 굴은 확장 가능
- 일어나고 낙하까지는 조금 시간이 있음 (내부. 나중에: 왜 오늘은 낙하가 없지?)
- 적이 떨어지면 자동으로 전투되게 설정. 비 오고 눈도 내리며, 누워서 자기도 함. 침대 같은 것도 가끔 떨어짐
- 오프닝: 청광묵의 외눈이 (화면 가득). 저주: 실명 (?)에 걸린 후. 엔터 → 3초 → 엔터 가능 → 3초. 천천히 스킵.. 대화는 눌러야 넘어감
- 곡괭이로 (?) 돌을 캉캉 캐는 소리. 카리우스가 돌을 캐고 있음. "일어났나, 대장?"
- 그렇게 게임이 시작. 레베카: "잘 주무셨어요?" 청광묵: "대장! 달팽이 죽었다!"
- 그림: 레베카 · 가축 인광달팽이들
- 식량 배급: 낙하로 지속적으로 보급되나 풀 랜덤임. 채식 재배는 불가능. 그래서 굴을 내려가기도 해야 함. 재수 없으면 굶어요
- 상태창 그림: 왼쪽 장비 칸, 가운데 인물, 아래 특성 · 간략 스탯 · 스킬 / 탭 ★ · 장비 · 아이템 / 인물 목록 / 스탯 → 장비 설명 · 장비 스킬 (있으면)

### 5쪽: 굴 꾸미기 · 첫 보스 적뢰까지

- 악기: 무드 올려 줌. 지금은 이모지로?
- 부서진 것들 에셋 필요. 카리우스 스킬 이미지 필요
- 그렇게 문을 다 파면 본게임 시작. 두구두구!! 문을 확대.. 그러나 아무 일도 없음 ("뭐야?" 대사)
- 그리고 하루 경과. 그날은 마지막 준비날임 (즉, 컨트롤로 이길 수밖에)
- 그날 자기 전 경고. 카리우스: "불길하다~~" (⚠ 표시)
- 정리 창: "다음날 낙하에는 천벌: 적뢰가 강림합니다. 정말로 넘기시겠습니까?" YES / NO. 하면.. (세이브 불가)
- 다음날 낙하 → 정적 & 컷신 재생 → 보스 전투 시작
- 폭우 20턴: 근데 평소랑 다른 폭우 겁나 내리침. 대사 한 마디씩, 2턴 후 → 강림: 적뢰

## 3. 분석

### 3.1 핵심 고리: 낙하가 가챠다

- 2쪽 "이 게임에서 가챠란 뭘까? 난 그걸 낙하라고 생각했는데"가 메모 전체를 묶는 답
- 낙하로 오는 것: 적 (자동 전투), 침대 · 가구, 장비 · 유물 (초기 낙하물: 어부의 창 · 목걸이), 식량 (풀 랜덤), 날씨 (비 · 눈 · 폭우), 보스 (천벌 예고)
- 그래서 뽑기 화면 (10칸 결과)도 "오늘 떨어진 것" 결과표로 읽을 수 있음
- 좋은 점: 돈을 넣는 뽑기가 아니라 세계 규칙. 운이 나쁘면 굶는다 → 탐사로 메꿔야 한다는 압박이 자연스럽게 생김

### 3.2 하루 고리 (굴) 와 탐사 고리

- 아침: 기상 → 잠깐 자유 시간 → 낙하 (내용물 랜덤, 적이면 자동 전투)
- 낮: 문 부수기 (하루 5시간?), 무드 관리 (악기), 쓰레기 청소 (적 시체가 쌓임), 가구 만들기, 굴 확장
- 밤: 자기 전 경고 · 다음날 예고 (정리 창), 넘기면 세이브 불가
- 탐사: 따로 고르는 콘텐츠. 어두운 맵, 공략조 · 정찰조, 생환 실패가 잦음. 식량이 모자라면 내려가야 함
- 지금 3D 시제품 (예고 장판 · 투창 · 지시)은 탐사 · 보스전 쪽에 그대로 들어감. 굴 생활은 IDEAS v1.0의 2D 횡 방이 잘 맞음

### 3.3 등급 체계 (★ 와 S ~ F)

- ★: 태생 (희귀도). 전투력 차이 아님. 1★ 간호사 ~ 5★ 포렌
- 스킬 · 특성 등급: S A B C D E F 7단계, 색으로 구분. 웬만해선 C부터 시작
- 메모에 나온 특성: 근력 · 괴력 · 발화탄 (~5단계) · 축복 · 불사 · 재생 · 사격 · 갑피 · 개조된 신체
- 즉 동료의 차이는 ★이 아니라 특성 조합과 등급. 성장 = 등급 올리기

### 3.4 장비 규칙 (안)

- 동료: 장신구 · 방어구는 착용, 그 계열 스킬 사용 가능
- 무기: 동료는 공격 버프만, 특수 스킬은 주인공만 (일단)
- 획득: 보상으로, 중복 획득 가능
- 종류: 유물 · 장비 · 유물장비 · 보스장비 · 인카운터 유물 · 인카운터 장비 (보스유물은 없앰). 도감의 지금 분류와 거의 맞음 (유물장비만 새로 생김)

### 3.6 NPC · 인카운터

- 노랑고양이 (코라): 악마종 (?), 이벤트 인카운터
- 차륜 (노랑): 인카운터만, 비전투
- 마리 & 와킨: 비전투, 4성 전력, 이벤트로 도움 요청권
- 오닐 & 칼: 검은 공간 인카운터. 출구 알려 주기 → 재조우 시 성향에 따라 선물, 히든 현자의 검 (도감 현자 세트와 연결)
- 대장군: 중간 보스, 묵직한 검격 · 타격, 특수 능력 없음
- 퀸 아리안: 보스 아닌 강적, 적대적이지 않음

### 3.7 첫 판 흐름 (프롤로그 → 적뢰)

1. 암전 · 실명 저주. 청광묵의 외눈이 화면 가득. 느린 스킵 (엔터 → 3초 → 엔터)
2. 낙하한 주인공에게 청광묵이 달려듦 → 붙잡아서 첫 전투 끝 (튜토리얼)
3. 돌 캐는 소리. 카리우스 "일어났나, 대장?" 레베카 "잘 주무셨어요?" 청광묵 "대장! 달팽이 죽었다!" (가축 인광달팽이)
4. 초기 낙하물: 어부의 창 · 목걸이 + α (고정)
5. 며칠 동안 굴 생활: 문 파기 · 식량 · 무드
6. 문을 다 팜 → 두구두구 → 아무 일도 없음 ("뭐야?")
7. 하루 경과, 마지막 준비날. 자기 전 카리우스 "불길하다~~"
8. 정리 창: "다음날 낙하에는 천벌: 적뢰가 강림합니다" YES / NO (세이브 불가)
9. 다음날: 정적 · 컷신 → 평소와 다른 폭우 → 대사 한 마디씩, 2턴 후 강림 → 보스전 (컨트롤로만 이김)

### 3.9 열린 질문
