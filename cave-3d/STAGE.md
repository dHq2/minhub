# 대사 실험장 대본 쓰는 법 v1.0

v1.0 (2026-10-30): 처음 (게임 v0.95 · stage.js v1.0)

뮤직비디오 · 게임 설명 영상 · 스토리 모드 대사를 시험하는 곳. 미연시처럼 골반까지 나오는 스탠딩 인물과 아래 대사창으로 보여 줌. 배경은 투명이라 영상에 그대로 얹을 수 있음.

## 들어가기 · 키

- 굴에서 Esc → '대사 실험장 (영상 · 대사)'. 또는 주소 끝에 `#stage`
- Space · → · Enter · 화면 클릭: 다음 박자. 글이 찍히는 중이면 한 번에 다 보임
- ← · Backspace: 한 박자 뒤로 · R: 대본 다시 읽고 처음부터 (빈 화면)
- Tab: 대본 창 열고 닫기 · Esc: 녹화 멈춤 (녹화 중이 아니면 창 열고 닫기)

## 대본

한 줄이 한 박자 (Space 한 번). 연출 줄 ([…]) 은 바로 다음 대사와 같은 박자에 일어남.

```
이름: 대사                말하는 사람만 밝게, 나머지는 어둡게
이름(표정): 대사          그 표정 그림으로 바꾸고 말함
: 대사                    나레이션 (모두 어둡게, 이름판 비움)
콜론 없는 줄              나레이션
|                         대사 안에서 줄 바꿈
// 메모                   무시됨
```

연출:

```
[등장 이름 자리 표정]     옆에서 스윽 (자리 · 표정은 빼도 됨)
[퇴장 이름]  ·  [퇴장 모두]
[표정 이름 표정]
[이동 이름 자리]          스르륵 옮김
[흔들 이름]  ·  [깡충 이름]
[멈춤]                    대사창 없이 한 박자 쉼 (모두 밝게)
```

- 자리: 왼쪽 · 왼쪽2 · 가운데 · 오른쪽2 · 오른쪽
- 처음 말하는 인물은 저절로 등장. 주인공 (기본 인주) 은 오른쪽, 나머지는 왼쪽 → 왼쪽2 → 오른쪽2 순
- 인물은 늘 화면 가운데 쪽을 봄 (그림이 반대를 보면 저절로 뒤집음)

## 설정 줄 (대본 어디에 써도 됨)

```
설정 속도 30                  글자 / 초
설정 어둡기 0.55              말 안 하는 인물 밝기 (0 ~ 1)
설정 글자크기 48  ·  설정 줄간격 58      (갈무리 모노 11 은 12 의 배수가 또렷함: 36 · 48 · 60)
설정 글자색 #2b2420  ·  설정 이름색 #f1e8d8
설정 글자그림자 0 2 4 rgba(0,0,0,.4)    옆 · 아래 · 번짐 · 색  (없음 = 끔)
설정 이름그림자 …  ·  설정 창그림자 …  ·  설정 인물그림자 …   (같은 꼴)
설정 소리 끄기  ·  설정 소리크기 0.5
설정 주인공 인주  ·  설정 인물크기 1
설정 등장 0.45  ·  설정 퇴장 0.35        (초)
설정 녹화fps 30                (또는 60)
```

인물 하나만 맞추기:

```
인물 모닝스타 크기 1.1 옆 -40 위 10 자르기 0.55 소리 360 뒤집기
```

크기 · 옆 · 위 = 그 인물만 · 자르기 = 그림 위에서부터 보일 비율 (골반까지) · 소리 = 전자음 높이 (Hz) · 뒤집기 = 좌우 반대로

## 인물 그림

- 지금은 인주 · 모닝스타 · 옐로. 스탠딩 대화 그림이 오기 전엔 게임 그림을 골반까지 잘라 임시로 세움 (대본 창 '인물' 칸에 '임시 그림')
- 그림 파일을 화면에 끌어다 놓거나 '그림 넣기…' → 파일 이름 = `이름_표정` (예: `모닝스타_웃음.png`, `인주.png` = 기본). 바로 들어감
  - 넣은 그림은 그 브라우저에만 보관됨. 게임에 아주 넣으려면 그림을 Claude 에게 주면 됨
- 없는 표정을 쓰면 기본 그림으로 (대본 창에 알림)

## 녹화

- 녹화는 늘 투명 배경 webm (영상 vp9 + 전자음 opus, 1920 × 1080). 미리보기 바탕 (체크 · 초록 · 파랑 · 검정 · 흰색) 은 화면에서만 보임
- '● 녹화': 빈 화면에서 시작 → Space 로 진행 → 마지막 대사 뒤 Space (또는 Esc) → 저장 창
- '↻ 방금 진행 그대로 녹화': 방금 Space 로 한 진행을 누른 박자 그대로 다시 돌려 찍음 (연습한 대로 깨끗하게 한 번 더)
- 저장이 안 됐으면 '⬇ 마지막 녹화 다시 저장'
