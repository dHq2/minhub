# 원정 층 구상 v1

v1 (2026-10-05): 첫 초안. 민수 방향 정리 — 핵앤슬래시가 아님. 층 하나 = 장면 하나. 아름답게. 뭐가 나올지 모르는 로그라이크.

## 1. 방향

- 핵앤슬래시가 아님: 빨리 깨는 게 목표가 되면 안 됨. 장비 · 낙하가 우수수 쏟아지면 안 됨
- 층 하나 = 하나의 장르 또는 하나의 인카운터 (방 · 복도 미로 재활용은 버림)
- 층마다 셋 중 하나의 결
  - 시련: 매우 어렵고 넓음. 지나가는 것 자체가 목표
  - 공백: 아무것도 없음. 걷기 · 소리 · 하늘. 가끔 무언가 하나
  - 풍경: 아름다움. 쉼 · 만남 · 이야기
- 어떤 층이 나올지 모름 (로그라이크). 1층만 고정

## 2. 1층 — 회색 대지 (고정)

2D판의 1층을 그대로 옮김.

- 길고 넓은 가로 대지 (2D: 44칸). 하늘은 어두운 회색 그라데이션, 멀리 언덕 두 겹 (그림)
- 하늘에서 가끔 재가 내림
- 들어갈 때 달 그림 한 장: "달에는 길이 없었다. 지도만 있었다." (cave-game/assets/load_moon.jpg)
- 가는 길: 무리 두세 번 (검사 · 검방패병 · 창병 · 붉은 망토 궁수), 강적은 곤봉 거한 하나
- 끝: 무덤 → 알현실 (cesar_back.png) → 관 속의 세자르. 세자르는 혼자, 2D 원본 성능 그대로

## 3. 층 카드 (2층부터, 원정마다 섞어서 뽑음)

| 카드 | 결 | 내용 | 바탕 (있는 그림) |
|---|---|---|---|
| 안개 늪 | 시련 | 넓은 늪 · 풍차 · 웅덩이. 색을 잃은 자 · 고블린이 수로 밀어붙임 | 2D mist |
| 붉은 가시 성당 | 시련 | 성당 그림을 뒤에 세운 긴 회랑, 끝에 강적 | cathedral_back.jpg |
| 왕관의 회랑 | 시련 | 푸른 횃불 · 카펫. 거한 · 검방패병 · 벤킨 | 2D gallery |
| 기나긴 해변 | 풍경 | 가로로 길고 넓은 모래사장, 카메라 조금 멀리, 바다 그림 배경. 가다 보면 말대가리가 선베드에서 흔들흔들 | art/enc/horsehead.webp |
| 오딜의 방 | 풍경 | 방 하나와 오딜뿐. 쉼 + 가면 | room_odile.jpg |
| 빈 들판 | 공백 | 아무것도 없음. 바람 · 풀. 끝까지 걸으면 계단 | — |
| 무너진 다리 | 공백 | 안개 위 좁은 다리 하나. 가끔 무언가 떨어져 있음 | — |
| 촛불 왕의 카드판 | 풍경 | 2D 만남 그대로 | 2D 만남 |

- 같은 카드는 한 원정에 한 번
- 시련이 두 번 연달아 나오면 다음은 풍경 또는 공백 (숨 고르기)
- 카드는 나중에 계속 늘림. 한 장 한 장 공들여 만듦 (재활용 배치 없음)

## 4. 보상 · 낙하 줄이기

| | 지금 | 바꿈 |
|---|---|---|
| 일반 적 | 20% 소모품 · 6% 장비 | 장비 없음 · 소모품 가끔 |
| 강적 | 장비 확정 | 시련 층 끝에서만 하나 |
| 상자 · 묻힌 것 | 층마다 여럿 | 층에 하나 있을까 말까 |
| 보스 | 유물 1 · 장비 2 | 유물 1 |
| 굴 낙하 | 매일 | 이틀 · 사흘에 한 번, 대신 하나하나가 사건 |

## 5. 층 사이

- 계단 앞에서 "다음은 무엇일까" — 카드 뒷면만 보임 (뭔지 모름)
- 돌아갈지 더 내려갈지 고르는 무게: 횃불 · 식량 · 다친 동료

## 6. 같이 고칠 것 (앞서 정리한 것)

- 적뢰 카메라: 지상전은 원래대로, 공중전만 완화된 락온 (전신 · 뒤쪽이 보이게, 빙글빙글 없음)
- 가리는 지형은 반투명 + 실루엣
- 위에서 보는 층은 그림을 눕힘
- 쥐 기사 끔 (포렌 때 다시)
- 기절한 아군은 일으켜 줘야 함, 다리 절단 (드묾)
- 슬라이딩 · 드롭킥은 빈틈일 때만 강함, 아니면 막히고 밟히거나 잡혀서 던져짐
- 태클: 투창처럼 조준 · 달리며 어깨빵 · 레슬링 자세 → 그래플링
- 모바일: 원정 준비 창 크기, 알림 겹침, 빈 소모품 칸 숨김
