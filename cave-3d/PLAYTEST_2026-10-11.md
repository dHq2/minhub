   - 반시체 → 수술 = 평생 후유증 하나. p6 은 1 · 2 · 4일째 반시체 → 5일째에 이미 영구 셋. 인주는 매번 나가는 주인공이라 영구 손해가 판 전체를 깎음.
   - '어렵고 잘 죽어야' 인데 죽을 때마다 영구히 약해지면, 날이 갈수록 더 못 이기는 쪽으로만 감.
2. 다음 날 체력이 바닥에서 출발 → 연쇄
   - 반시체 뒤 수술 = 30% · 잠 회복 35% → 다음 원정을 20 ~ 40% 로 출발 (p6: 36/110 · 26/115 · 35/119). 1층 첫 무리 (궁수 둘 · 검방패병) 에서 바로 쓰러짐 → 또 반시체.
3. 원정 인원에 제한이 없음 — 결국 '머릿수' 가 진행
   - 금화가 모이면 기원을 거듭 (+ 포획 · 낙하) → p7 8일째 11명 · 14일째 32명, p6 11일째 11명 · 14일째 22명이 한꺼번에 나감. 10명을 넘긴 뒤로는 쓰러짐 0 ~ 1 · 3층.
   - 1층이 어렵다가 사람이 많아지면 갑자기 쉬워짐 (어려움이 실력이 아니라 인원으로 풀림). 누구를 데려갈지 고르는 재미 · 끼니 (입장권) 의 무게도 사라짐 (끼니 0 으로 11명이 나가도 배고픔 −15% 뿐).
4. 보스 진척이 매번 0 으로
   - 세자르까지는 4일째부터 닿음. p6 은 827 → 474 → 63 (거의 잡음) → 458 → 924 까지 깎고도 매번 1595 로. 결국 머릿수가 늘어난 뒤에 잡음 (p7 6일째 6명 · p6 11일째 11명).
   - 잡고 나면 1층은 그냥 지나가는 길 (보스는 다시 안 나옴) 인데, 원정은 늘 1층부터 → 깊은 층에 가려면 매번 1층을 다시 걸어야 함.
5. 죽는 까닭이 거의 둘
   - 받은 피해: p6 은 세자르 50% · 붉은 망토 궁수 26% (둘이 4분의 3). 1층 잡몹 중엔 궁수가 압도적. 어려운 건 좋지만 어려움의 종류가 한 가지라 금방 단조로워질 수 있음.
6. 원정에서 끼니를 거의 못 가져옴
   - 빵 · 사과 · 고기는 주우면 물약 칸에 저절로 들어가 싸우다 먹게 됨 → 굴 창고로 끼니 0 (거의 모든 원정). 끼니는 낙하에 기댐. 많이 가져온 건 3층까지 간 날뿐 (3 · 6).
7. 레벨은 오르지만 상처가 더 깎음
   - p6 인주 10일째 Lv 5, 최대 체력 160 → 114 ~ 134 (영구 상처 · 후유증 때문). 레벨업 = 강해짐이 안 느껴짐.

### 개선점 (난이도 = 싸움은 그대로 두고 할 수 있는 것)
1. 원정 인원 제한: 인주 + 셋 (넷) — 누구를 데려갈지가 선택이 되고, 1층의 어려움이 머릿수로 풀리지 않음. 굴 식구가 많을수록 '쉬는 사람 · 굴 지키는 사람' 이 생김 (3단계 방어전과 이어짐)
2. 상처 속도 맞추기: (a) 원정 간 날도 이틀씩 · (b) 같은 부위는 겹치지 않고 날짜만 늘게 (지금은 심장 9일이 계속 새로 붙음) · (c) 한 원정에서 한 사람에게 붙는 상처는 둘까지
3. 쉬는 날을 보이게: 잠자리 이름표에 '오늘은 쉰다 — 체력 +35% · 상처 이틀' · 원정 준비 창에 상처 있는 동료를 빨갛게 ('다치면 더 크게 다침')
4. 식량은 물약 칸에 저절로 넣지 않기 (넣더라도 '굴 끼니' 표시) — 먹을지 들고 갈지 고르게
5. 보스 진척: 세자르를 깎은 만큼 사흘 동안 덜 찬 채로 (깎은 양의 30%) — 또는 세자르의 동작을 볼 때마다 도감에 '읽음' (다음엔 예고가 조금 일찍)
6. 지름길: 쓰러뜨린 보스의 층은 다음부터 건너뛸 수 있게 (원정 준비 창에서 '2층부터')
7. 궁수 대응을 보이게: 레베카 방패 뒤에 서면 화살을 막아 줌 (지금은 레베카 자신만) · 바위 엄폐 표시 · 화면 밖에서 오는 화살 예고 화살표

### 다른 방향 (구조 — 민수 결정)
- A. 하데스식: 전멸 · 반시체는 굴에서 다 나음. 상처는 그 원정 안에서만 무게. 굴에 쌓이는 건 식구 · 유대 · 노련함 · 유물 · 도감. '어렵고 잘 죽어야' 와 가장 잘 맞음 — 죽어도 다음 판은 같은 출발선에서 조금 더 노련하게.
- B. 다키스트 던전식 (지금과 가장 가까움): 영구 상처는 남기되, 인주는 지휘관 — 매번 안 나가도 됨 (동료만 보내는 원정) · 요양 (굴 가구) · 후유증을 고치는 드문 수단 (성해포 · 레베카의 피 · 의사 식구).
- C. 흉터 = 노련함: 후유증마다 페널티 + 보너스 (절뚝임 → 버팀 + · 손 떨림 → 분노 (치명 +) · 안구 → 귀가 밝아짐 (뒤 기습을 미리 앎)). 상처를 이기고 살아남은 수가 노련함 단계를 올림 (설계 3.1). 상처투성이 = 베테랑.
- 추천: A 를 바탕에 C 를 더함 — 원정 안의 상처는 무겁게, 굴로 돌아오면 흉터 하나만 이야기로 남고 흉터는 노련함. B 의 '동료만 보내기' 는 3단계 (굴 정비 · 방어전) 와 함께.

### 로그라이크 재미 (지금 모자란 것)
1. 판 안에서 고르는 성장이 없음: 레벨업은 저절로 · 줍는 건 무작위 → 원정 안에서 '고르는' 순간이 갈림길 · 카드뿐. 무리 하나를 정리하면 셋 중 하나 (기술 하나 · 유물 조각 · 동료 강화 · 회복) — 판마다 다른 조합 (빌드).
2. 위험 · 보상의 저울: 더 갈까 돌아갈까. 깊이 갈수록 보상 배수 (3층 원정 금화 +116 ~ +203 = 1층의 4 ~ 5배 — 이미 있음) 를 귀환 줄 곁에 보여 주기 ('지금 돌아가면 …').
3. 1층이 손으로 짠 고정 맵: 몇 번이면 외워짐. 뼈대는 그대로 두고 무리 배치 · 강적 변이 · 날씨 · 문 이벤트를 판마다 섞기.
4. 실패에서 남는 것: 보스 패턴 읽음 · 도감 · 식구의 한마디 (레베카: '오늘은 거의 잡을 뻔했어요') — 다시 하고 싶게.
5. 원정 시작의 선택: 동료 (넷) · 보급 (횃불 · 붕대 · 끼니) · 유물 하나를 고르고 나감 (지금은 난이도 · 횃불만).
6. 조합 · 유대 (2단계 계획): 같이 살아남은 원정이 쌓이면 둘이 같이 쓰는 기술. 인원 제한이 있어야 '늘 같이 가는 짝' 이 생김.

1. 큰 그림 (마계장군 A · 곤봉 거한 · 붉은 망토 궁수) 이 인주를 가림 → 가려지면 인주 윤곽선 · 큰 그림 반투명

3. 아래 기술 줄: 버튼 11개가 같은 모양 — 쓸 수 없는 것 (재사용 대기 · 상처로 못 함) 흐리게 · 재사용 시간 원
