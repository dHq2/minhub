# 망각 3기 보충 (mangak_g3)

- 이름: 망각 · 등급: 보스 · 폴더: "보스 망간" (+ 하위 폴더 "이전버전")
- 역할: 보스 (2기와 같음) · 키 6.6m (길이 10m) · 무게 약 18톤

## 망간 = 망각 판단
- 00_원본_참고.png (264x301): 붉은 머리칼 · 노란 외눈 · 해골 같은 검은 얼굴 · 더듬이 뿔 두 개 · 마디진 촉수 · 회녹색 비늘 깃털. 2기 망각 초상과 똑같은 생김새. 글자는 없음.
- 그림 파일 이름도 모두 "망각의 …". 그래서 폴더 이름 "망간" 은 "망각" 의 오타 (또는 다른 표기) 로 보고 새 slug 를 만들지 않음.

## 그림 목록
1. 망각의 붉은 눈 괴수.png (1536x1024) = 2기 "거대괴수 10M길이 [망각].png" (idle) 와 화소까지 똑같음 → 자르지 않음.
2. 망각의 붉은 눈, 해골 턱의 덫.png (1536x1024) = 2기 "망각3.png" (special) 와 화소까지 똑같음 → 자르지 않음.
3. 이전버전/붉은 외눈 갑각 괴수.png (2048x768) = 2기 "망각2.png" (walk · attack) 와 화소까지 똑같음 → 자르지 않음.
4. 붉은 머리 두 몬스터의 대기와 공격.png (2048x768) — 새 그림. 망각2 와 같은 구도의 다시 그린 판.
   - 왼쪽: 꼬리 들고 네 발로 버티고 선 자세 → walk_b
   - 오른쪽: 앞발 갈퀴를 쭉 뻗으며 뛰어드는 자세 (입 벌림) → attack_b
   - 두 마리 다 오른쪽 봄 (뒤집기 없음).
- "두 몬스터" 는 하수인 · 별개 괴수가 아니라 망각 한 마리의 대기 · 공격 두 동작 (생김새 같음). 별도 slug 만들지 않음.
- 배율 1.13: 새 그림은 인물이 작게 그려져 (원본 높이 약 616px), 2기 walk 키 (695px) 에 맞춤. 비늘 사이 흰 구멍 따로 지움.
- ax: 네 발 짐승이라 몸 가운데로 손으로 고침 (walk_b 500, attack_b 470. 자동값은 json ax_auto).

## 새 그림과 2기 그림 차이
- 새 판은 머리칼이 짧은 단발로 매끈하고, 몸 비늘이 더 밝은 녹색 · 근육 결이 또렷함. 왼쪽 그림은 촉수가 있고 오른쪽 그림은 없음 (2기 망각2 와 같음). 섞어 써도 무방.

## 새 기술 제안 (2기 kit 와 겹치지 않음)
- 갈퀴 덮치기 (attack_b): 0.8초 낮췄다가 10m 도약 돌진, 폭 3m 줄 판정, 큰 피해 + 넘어뜨림 1.5초. 벽에 부딪히면 2초 멈칫.
- 망각의 그림자 (walk_b): 6초 동안 반경 8m 로 맴돌며 발자국 장판 (원 1.5m, 3초) — 밟으면 기술 쿨타임이 멈춤 ('잊음'). 꼬리 뒤 4m 접근 시 꼬리 가시 반격.
- 패시브 외눈 추적: 정면 60도 안의 적은 은신이 풀림.
