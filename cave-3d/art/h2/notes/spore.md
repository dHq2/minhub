# 포자 (spore)

- 이름: 미상 — 폴더 이름 "포자 적". 원본 참고 (214x282 캡처) 에 글자 없음. 시트 파일 이름 "황금 반점 공허의 3단 보스 포즈".
- 등급: 글자 없음, 시트 이름에 '보스' → 강적 ~ 지역 보스급. 역할: 적 (말 없는 괴물).
- 3기 (gen 3).

## 생김새
- 키 약 2.4m (머리 껍질 포함), 깡마르고 긴 몸을 해진 로브로 감쌈 (90kg 정도).
- 머리: 노란 · 황금색 구멍 숭숭한 버섯 / 해골 같은 껍질 (포자 덩어리). 껍질 아래는 검은 공허, 목에 붉은 핏줄 (빛남).
- 회흑 해진 로브 여러 겹, 가운데 연회색 천에 레이스 같은 구멍 무늬, 가슴에 은 브로치.
- 손: 아주 길고 검은 갈퀴 손가락 (무기 대신).
- 원본 참고: 보라 · 회색 눈알 무늬 배경 앞의 황금 껍질 머리 + 붉은 핏줄 목 클로즈업.
- 팔레트: #2a2a2a (로브) · #555555 · #8a8a88 (연회 천) · #c79a3a (황금 껍질) · #c0304a (핏줄)

- 근접 덮치기 + 포자 장판형 괴물. 머리가 약점.

## 게임 제안
- 기본기: 갈퀴 할퀴기 2연타 (앞 2.5m 부채꼴).
- 기술: 공허의 아가리 (attack, 4m 덮쳐 물고 붙잡기) · 황금 포자 구름 (front, 5m 원 독 장판 + 회복 감소) · 포자 번식 (idle, 장판 위 쓰러진 적에서 졸개 소환).
- 패시브: 공허의 껍질 — 몸통 피해 30% 감소, 머리 맞으면 1.5배 (약점), 포자 장판 위 회복.
- 능력치: hp 2600 · atk 52 · spd 4.8 · 무게 90kg · 키 2.4m
- 적성: 근접 4 · 창 0 · 활 0 · 총 0 · 마법 4 · 은신 2
- 성향 beast · 보직 선봉 · 배낭 4
