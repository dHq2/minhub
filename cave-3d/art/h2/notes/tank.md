# 중장 탱크 (tank)

- 이름: 탱크 · 등급: 2성 · 폴더: "2성 중장 탱크(SF)"
- 역할: 동료 (방패 탱커). 이름의 (SF) 와 빛나는 청록 바이저 → 미래 장비를 쓰는 기사.

## 생김새
- 약 2.05m (뿔 포함), 아주 크고 두꺼운 체격.
- 머리: 쌍뿔 달린 회색 투구, 얼굴은 검은 가리개, 눈 자리에 청록빛 바이저 한 줄. 목에 짙은 천 목도리 + 이빨 목걸이.
- 옷: 회색 판금 전신 (얼룩 무늬 닳은 금속), 짙은 회색 천 앞치마 · 망토, 가죽 허리띠 주머니.
- 무기: 가시 철퇴 (한 손) + 큰 방패 (십자 · 갈래 무늬).
- 팔레트: #515050 · #a3a1a2 (판금) · #2d2d2d (천) · #2fd6d0 (바이저) · #747374

## 그림 목록
1. 1000017917.png (실제 jpeg, 1024x1536) — 정면 원화 → portrait.webp · face.webp.
2. 청록 바이저의 쌍뿔 탱크 기사.png (1024x1536 png) — 1번과 같은 그림 → front.webp (배율 따로 0.472).
3. 회색 갑옷 기사의 대기와 공격 자세.png (1536x1024) — 왼쪽 = 대기 → idle, 오른쪽 = 철퇴 아래로 치기 → attack. 방패 · 뒷발이 겹쳐 칸을 칠해 나눔.
4. 회색 뿔 기사 두 전투 포즈.png (1536x1024) — 왼쪽 = 대기 2 → idle2, 오른쪽 = 철퇴 머리 위로 치켜듦 → attack2. 오른쪽 그림은 왼쪽을 봐서 (바이저가 투구 왼쪽) 뒤집음.
5. 뿔 기사 두 전투 포즈.png (1774x887) — 왼쪽 = 숙여 철퇴 낮게 쓸기 → low, 오른쪽 = 방패 앞 · 철퇴 뒤로 젖힘 → windup.
6. 뿔투구 기사, 수비와 전복 포즈.png (1774x887) — 왼쪽 = 수비 → guard, 오른쪽 = 전복 (뒤로 넘어져 주저앉음) → down (dead 도 이것).
- 배율 0.709 (3번 왼쪽 idle 키 988px → 700px). 바탕 흰색, 효과 없음.

## 싸움 방식 추정
- 철퇴 + 큰 방패 근접 (1.8m), 느리고 무거움. 내려찍기 · 낮게 쓸기로 넘어뜨리는 형.

## 게임 제안
- 기본기: 철퇴 치기 (attack).
- 기술: 내려찍기 (windup→attack2, 2m 원형 충격) · 다리 쓸기 (low) · 강철 방벽 (guard, 80% 막기 + 어그로).
- 패시브: 청록 바이저 (SF) — 어둠 · 연기 속 적 보임, 넘어짐 저항 +60%.
- 능력치: hp 520 · atk 22 · spd 3 · 무게 140kg · 키 2.05m
- 적성: 근접 3 · 창 1 · 활 0 · 총 1 · 마법 0 · 은신 0
- 성향 knight · 보직 선봉 · 배낭 14

## 빠진 동작
- walk, hurt, dead (down 으로 대신), SF 장비를 쓰는 skill 동작.

## 그림끼리 다른 점
- 원화 · front 는 방패가 더 길고 무늬가 갈래 모양, 시트 그림은 십자 무늬. 몇 장은 목도리가 더 두툼함. 색은 모두 같은 회색.
- 이 폴더에 다른 작업자가 넣은 portrait2.webp · face2.webp 가 있음 (내 것 아님).
