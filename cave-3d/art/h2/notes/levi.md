# 레비 (levi) — 4성

- 폴더 이름: 4성 악마 소환사 레비
- 역할 추정: 동료 (악마 계약 소환사 + 소총수). 적 진영 소환사로도 쓸 수 있음
- 단체 원화 '4성 5인 원화.jpg' 맨 왼쪽 (뒤에 검은 괴수). 아래 글자 "레비/건/풍야/소스차/투구(게)" 중 첫 번째, '스카웃 가드 5인, 굴의 20층' 표시

## 생김새
- 키 약 1.68m, 마른 근육형 여성. 허리까지 오는 갈색 장발 (부스스한 포니테일), 회색 눈, 이를 악문 불안한 표정
- 옷: 올리브 줄무늬 전투 셔츠 (소매 걷음), 검은 조끼, 위장무늬 카고 바지, 베이지 전투화, 손가락 없는 검은 장갑, 허리 큰 탄약 주머니
- 팔레트: #4b4a40 (올리브) · #636054 (밝은 올리브) · #5a4630 (갈색 머리) · #b8ab90 (전투화 베이지) · #201f1b (검정 장비)
- 무기: AR 계열 돌격소총 (조준경 · 소염기). 소환수: 숯빛 비늘의 거대 그림자 용 (붉은 눈, 몸 끝이 그림자로 흩어짐) → levi_beast

## 그림 목록 (8개, 중복 1쌍)
1. 레비 기본.jpg (1024x1536, 흰 바탕) — 서서 뒤돌아봄, 소총 아래로. 아래 6번과 같은 그림 (jpg 압축본, 차이 평균 0.7) → 쓰지 않음, 6번 png 사용
2. 검은 괴수를 지휘하는 불안한 소환사.png (1024x1536) — 레비 + 뒤의 그림자 용. 1동작 → command (원래 왼쪽 봄 → --flip). portrait.webp 원본으로도 씀. 용 그림자 꼬리 사이 흰 구멍이 많아 구멍 메움 처리 (아래 '처리')
3. 무릎 강타와 소환 자세의 전투 스프라이트.png (1536x1024) — 2동작: 왼쪽 무릎 꿇고 땅을 주먹으로 침 (파편 효과, 몸에 붙어 있어 포함) → special, 오른쪽 두 손 뻗은 소환 자세 → summon2. 둘 다 오른쪽 봄
4. 소총 든 올리브 여전사의 두 자세.png (1774x887) — 2동작: 무릎 쏴 → crouch, 누운 채 겨눔 → down
5. 숯빛 거대 용형 소환수의 대기와 돌진.png (1774x887) — 소환수만 2동작: 대기 → levi_beast/idle, 돌진 → levi_beast/dash
6. 올리브 라이플 사수의 두 포즈.png (1536x1024) — 2동작: 소총 낮춘 대기 → ready, 견착 사격 (총구 불꽃 포함) → shoot
7. 올리브 병사의 소총 공격과 소환.png (1536x1024) — 2동작: 소총 휘두르기 → attack, 한 손 뻗은 소환 → summon
8. 올리브 전투복의 갈색 장발 정찰병.png (1024x1536) — 1번과 같은 그림 png → idle

- 배율: 시트 크기마다 그림 크기가 달라 '같은 게임 크기'가 되도록 시트별로 맞춤. 1024x1536 세로 = 0.463 (선 키 1512px → 700), 1536x1024 = 0.717 (ready 선 키 976 → 700), 1774x887 = 0.65 (전투화 · 머리 크기 비교로 1536 시트의 약 1.1배)
- 처리: 바탕 흰색 → 도구 기본 (th 38). 가장자리와 이어지지 않은 흰 구멍 (다리 사이 · 그림자 꼬리 사이)은 따로 지움 (닫힌 흰 영역 제거). shoot의 총구 불꽃 흰 중심은 지워졌다가 원래대로 되돌림

## 싸움 방식 추정
- 소총 원거리 사수 + 악마 소환. 위급하면 맨손 · 개머리판으로 근접 (attack, special '무릎 강타')
- 파일 이름 기술: 무릎 강타, 소환, 소총 공격

## 게임 제안
- 기본기: 소총 점사 (shoot), 근접 시 소총 휘두르기 (attack)
- 기술: 그림자 용 소환 (summon / summon2 → levi_beast dash 돌진), 무릎 강타 (special, 주변 충격 넉백), 무릎 쏴 (crouch, 정밀 사격), 지휘 (command, 소환수 강화 · 궁극기)
- 패시브: 계약의 그림자 — 체력 30% 아래에서 소환수가 한 번 막아 줌
- 능력치: hp 110 · atk 16 · spd 1.0 · 58kg · 1.68m
- 적성: 근접 2 · 창 0 · 활 1 · 총 4 · 마법 4 · 은신 2
- 성향 mage (소환), 보직 사수, 배낭 12칸

## 빠진 동작
walk/run, hurt, dead, 재장전, 점프. 소환수: 공격 (물기 · 할퀴기), 피격, 사라짐

## 그림끼리 다른 점
- 옷 · 색은 모든 그림이 같음. command 그림만 셔츠 무늬가 더 대각선이고 바지 위장무늬가 뚜렷함 (같은 사람)
- idle/command는 1024x1536 세로 원화 계열이라 선이 조금 더 가늘고 자세히 그려짐
