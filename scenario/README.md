# 시나리오 편집기 v1.0

v1.0 (2026-10-30): 처음. 3D 게임 대사 실험장 (cave-3d/src/stage.js v1.0) 의 재생 · 녹화를 떼어 와서, 대사 카드 · 인물 그림 편집 · 서버 저장을 얹음 (민수: 일러스트까지 편집할 수 있는 시나리오 편집기)

뮤직비디오 · 게임 설명 영상 · 스토리 모드 대사를 짜는 곳. 미연시처럼 골반까지 나오는 스탠딩 + 대사창, 배경은 투명, 투명 배경 webm 으로 녹화.

## 화면

- 위 띠: 시나리오 고르기 · 이름 · 새로 · 복제 · 지우기 / ▶ 처음부터 · ● 녹화 · ↻ 같은 박자로 녹화 · ⬇ 다시 저장 / 미리보기 바탕 (화면에만)
- 왼쪽 대사 카드: 한 장 = Space 한 번. 말하는 사람 · 표정 (그 인물에게 있는 그림만) · 대사 (Enter = 줄 바꿈) · 연출 (등장 · 퇴장 · 표정 · 이동 · 흔들 · 깡충 · 모두 퇴장). ⋮⋮ 를 끌어 순서 바꿈. '글로 보기' 로 글 대본과 오감
- 가운데 미리보기: 카드를 누르면 그 장면. Space 다음 · ← 뒤로 · R 처음부터 · Esc 녹화 멈춤
- 오른쪽
  - 인물: 이름 (바꾸면 모든 시나리오의 대사도 바뀜) · 그림 속 인물이 보는 쪽 (화면에선 늘 가운데 쪽을 보게 저절로 뒤집음) · 전자음 높이 · 크기 · 자리
  - 표정 그림: 넣기 (파일 · 끌어다 놓기, 파일 이름 = 표정 이름) · 이름 · 크기 · 옆 · 위아래 · 아래 자르기 · 보는 쪽 · 기본으로 · 흰 바탕 지우기 · 빼기. 미리보기에서 그림을 끌면 옮겨지고 휠로 크기
  - 설정: 글자 속도 · 어둡기 · 글자 크기 (갈무리 모노 11 은 12 의 배수: 36 · 48 · 60) · 색 · 그림자 4종 (글자 · 이름 · 대사창 · 인물) · 소리 · 주인공 (기본 오른쪽) · 인물 크기 · 등장 / 퇴장 시간 · 녹화 프레임

## 흰 바탕 지우기 (wb.js)

도감의 대화 표정 그림은 흰 바탕. 가장자리 (위 · 왼쪽 · 오른쪽) 에서 거의 흰색을 따라 번져 바탕을 찾고, 선으로 막힌 새하얀 빈틈 (머리카락 사이 · 사슬 고리 · 팔과 몸 사이) 도 지움. 가늘고 긴 흰 줄 (금속 반사) 은 남김. 바탕에 닿은 2px 띠는 흰 기운을 빼서 흰 테두리가 안 남게. 잘못 지워진 곳은 '되살리기' 로 누르고, 남은 빈틈은 '지우기' 로 누름. 결과는 자산 보관함에 올라가고, 원본 (orig) 은 남아서 다시 할 수 있음.

민수가 준 모닝스타 투명판 (놀림 · 기본) 과 견주면 바탕 · 빈틈이 거의 같음 (남은 차이는 두 그림이 몇 픽셀 어긋난 것).

## 저장 (아티팩트 저장소 · 자산 보관함)

- `cast/<id>`: `{ name, order, look: 'R' | 'L', pitch, size, dx, dy, ex: [{ k, src | blob, orig: { src | blob }, crop, scale, dx, dy, look?, tmp?, fw, fh, n, cols, fps (여러 장 붙은 그림) }] }`
- `scen/<id>`: `{ title, order, updated, opt: { 속도, 어둡기, 글자크기, 줄간격, 글자색, 이름색, 글자그림자 · 이름그림자 · 창그림자 · 인물그림자: [옆, 아래, 번짐, 색] | null, 소리, 소리크기, 주인공, 인물크기, 등장, 퇴장, 녹화fps }, beats: [{ id, kind: 'line' | 'rest', who, ex, text, fx: [{ k: in · out · ex · move · shake · hop, who, slot, ex }] }] }`
- 넣은 그림은 자산 보관함 → 화면은 `/_blob/<id>`. 기본 그림은 이 폴더의 art/cast/
- 저장소가 없는 화면 (파일로 연 경우) 에선 이 브라우저 (localStorage `scenario-editor-v1`) 에만
