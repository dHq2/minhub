- 보스가 보낸 사진 크게 보기(js/picview.js 새로): 말풍선의 작은 사진을 누르면 전체 화면 — 두 손가락 확대·끌어 옮기기·두 번 눌러 크게·마우스 휠, 여러 장이면 ‹ ›·옆으로 밀기, 아래로 밀면 닫힘. 「⬇ 저장」= 기기에 내려받기(다운로드 폴더), 되는 폰은 「공유」(사진첩 저장 등).
- 사진이 다시 켜도 남음: 보낼 때 긴 변 1280px 사본을 이 기기 IndexedDB(chatpic_<시각>)에 둠. 계정 동기화엔 안 실음(다른 기기는 「📷 캡처 n장」만). 말을 지우면 사본도 지움.
- 판 말투(지침): 항목은 '~해야 합니다'·'~이 있습니다'·'~입니다', 메모·코멘트는 '~입니다·~했습니다'. 명사로 끊지 않음.
- 세희 얼굴 표시: 보스가 준 얼굴 9장(art/f-*.webp). 세희가 쓴 메모엔 「세희 메모」+얼굴(보스가 고치면 보스 메모로 바뀜), 코멘트·「세희가 적음」에도 얼굴. 한마디 표정 도장이 글자 대신 얼굴 그림(누르면 바뀜, 도장 !!·O□O 추가).
- 한마디 필수: 판을 고친 차례에 세희가 set_line 을 안 쓰면 앱이 한마디만 한 번 더 시킴(보스에겐 안 보임). 앱이 연 판(날 바뀜·첫 판)·한마디가 빈 오늘 판은 임시 한마디를 먼저 씀 — 세희가 판을 고치면 새로 씀.
- 긴 답 문단 나누기: 지침(날짜 하나에 문단 하나) + 한 덩어리로 오면 날짜·요일로 시작하는 문장 앞에서 빈 줄(paraFix).
