- 보드에 「사진첩」 칸 새로 — 업무에 다시 꺼내 볼 사진(서류·안내문·공지·제출 목록·계약서·영수증·명함·표)을 날짜별 액자로 모아 둠. 인간관계 사진 단서(추억·단서)와는 따로.
- 보스가 보낸 사진이 업무 자료면 세희가 묻지 않고 사진첩에 넣고 한 줄만 보고("보드 사진첩에 넣었어요 — 신규입사자 제출서류 안내"). 화면은 안 옮기고 보드 견출지에 「볼 거」. 잡담 캡처·사람·음식·추억 사진은 안 넣음. 정리(분류·검색)는 나중에.
- 누르면 크게 보기(손가락 확대·저장·공유), ✕ 로 빼기(되돌리기), 「+ 사진」으로 직접 넣기.
- 용량: 이 기기엔 보낸 사진 사본(1280px) 원본, 계정 서버엔 1024px 작은 사본만(한 장 100~200KB). 서버 사본은 150MB 몫 — 넘으면 오래된 서버 사본부터 내리고, 처음 넣은 기기의 원본은 남김. 다른 기기에서 원본·사본이 다 없으면 「이 기기에 없음」.
- 보드 머리의 「갤러리·목록」 버튼이 보고서함이 아닐 때도 보이던 것 고침.
