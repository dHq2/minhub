- 달력 칠판에 낙서 — 받침대의 마커(빨강·파랑·검정)를 누르면 들어 올려지고, 손가락이나 마우스로 칠판에 그릴 수 있음. 같은 걸 다시 누르면 내려놓기(그때부터 다시 옆으로 밀어 보기).
- 지우개를 들면 문질러서 지움 — 낙서만 지워지고 일정 글씨는 그대로. 지우개를 두 번 톡 치면 이달 낙서 싹 지우기(알림에서 되돌리기).
- 낙서는 일정 글씨 위, 포스트잇 밑(실제 보드처럼). 달마다 따로, 이 기기에 남음 — 앱을 다시 열어도 그대로. 화면 크기가 바뀌어도 제자리.
- 받침대 마커를 크게, 받침대 둘레를 넉넉히 누르면 가장 가까운 마커를 집음(손가락이 바로 위 안내 줄로 빗나가던 것).
- 달력 쪽을 닫으면 마커는 내려놓음. tests/tcalink.js 새로.
