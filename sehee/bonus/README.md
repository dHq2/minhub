# 세희 보너스 업데이트 폴더 — v1

- 이 폴더(`sehee/bonus/`)는 보너스 방(제작기 2) 전용이다. 본체 `sehee/index.html`·`sehee/sw.js`는 메인 방만 고친다.
- 본체가 부팅 끝에 `bonus/bonus.js`를 한 번 불러온다. 다른 파일(css, 그림)은 bonus.js가 직접 불러온다.
- 본체와는 `window.SEHEE` 창구로만 잇는다. 창구 목록과 규칙은 인수인계 문서 4장.
- 보너스 버전은 B로 시작한다(B0.1, B0.2 …). 작은 변화도 bonus.js 맨 위 기록에 한 줄.
- 설정 → 보너스 업데이트 끔으로 기기마다 바로 뺄 수 있다.
