## v1.5.8 · C · 세희 기억 — 예전 자료 원문 다시 읽기, 자기 머리 알기, "소넷으로" 한 차례
- 까닭: 해독본·문서 전문은 보스의 최근 두 마디 안에서만 보내고 그보다 오래되면 앞 400자만 보냈다(글값 아끼려고). 그래서 몇 마디 뒤 "회식 대화 어디까지 나와?"에 세희가 원문이 없다고 답했다. 모델(Haiku) 탓이 아님.
- 잘린 자리 안내를 바꿈: "전문 N자는 앱에 그대로 있다 — 자료 번호 m…. 내용을 물으면 반드시 read_material 로 다시 읽고 답한다. 원문이 없다고 하지 않는다".
- 새 도구 read_material: id 없이 = 대화에 남은 자료 목록(최근 20), id = 전문(2만 자씩 나눠, next_from), find = 그 낱말이 나온 줄과 앞뒤 두 줄(줄번호). 'latest' = 가장 최근 자료. 읽으면 대화에 '… 원문을 다시 읽었어요' 줄. 평소엔 지금처럼 앞부분만 보내니 값은 그대로, 물을 때만 그 글값.
- 세희가 자기 머리를 안다: 지침 첫머리에 '지금 Haiku 5.5 · 긴 글·사진은 Sonnet 5.5', 머리를 바꾸라면 못 한다 하지 말고 ⚙ 설정 '세희 머리' 또는 "소넷으로"를 알려 줌.
- 보스 말에 '소넷/sonnet/큰 머리/깊게 생각'이 있으면 그 차례만 큰 머리(기다림 글: 'Sonnet 5.5로 깊게 생각 중'). 다음 차례는 다시 평소 머리.
- tests/tmaterial.js 추가.

## v1.5.3 · C · 판 항목 일간보고 방식(병행) + 업데이트 띠가 안 뜨던 것 고침
- 판 항목마다 처리 단추 넷 — 끝 · 알바노 · 내일 · 기억만(원파인데이 일간보고 오늘판과 같은 말). 누른 단추는 진하게, 오른쪽에 '✓ 알바노'처럼. 같은 단추를 다시 누르면 취소, 바로 아래 알림에서 되돌리기도.
  끝 = 完 도장과 같음(완 동그라미도 그대로 둠) · 알바노 = 우리 일 아님으로 닫음(完 도장 + 취소선, 다음 날로 안 넘어감)
  내일 = 오늘은 흐리게 접고 칸 머리에 '내일 N', 내일 판에 🔁 표시로 다시 올라옴 · 기억만 = '기억해둘 것' 칸으로 내림(취소하면 원래 칸으로).
- 오늘 새로 적은 일엔 🆕, 내일로 미뤘다 돌아온 일엔 🔁. 원래 있던 'N일째'·날짜·태그·메모칸(v1.5.1)은 그대로 — 병행.
- 누른 순서는 항목마다 wayLog 에 남는다(최근 20개). 세희는 읽기만 한다 — 알바노는 다시 꺼내지 않고, 내일은 오늘 먼저 꺼내지 않고, 기억만은 재촉하지 않는다.
- 업데이트(C 담당): v1.5.0 에 파일이 나뉜 뒤로 폰이 느리면 새 버전 소식이 보너스·사무실 파일보다 먼저 와서 오류로 조용히 멈추고 「새 버전이 있어요」 띠가 안 뜨던 것을 고침(js/update.js). tupd2 가 이걸로 실패하던 것.
