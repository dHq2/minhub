# v9.6.5 전우조는 한 몸처럼 · 개인 본능은 양쪽 — notes_965_v1.0.md

## 민수 말씀
- 전우조: 한쪽이 움직이면 연동되듯 따라가고 가능하면 붙어 있어야 함 (1 ~ 1.5칸)
- 유동적으로 — 한쪽이 명령받으면 따라다니고 · 뛰면 뛰고 · 서로 위급할 때 돕고 · 상대를 포위하고 · 후퇴할 때 같이 방어하며 후퇴
- 아군 모두 기본적으로 개인 본능을 가져야 함 (적과 같게)
- 지휘관 전술 · 판 시작 상황은 그대로 (아군은 플레이어가)

## 전우조 (pairStep — 양쪽 편 같은 규칙 · 명령을 받은 몸은 명령대로)
| 상황 | 하는 일 |
| 짝이 스스로 움직임 (명령 · 뜀 · 걸음) | 바로 연동 — 가는 쪽의 어깨 옆 1.1칸에 붙어 따라감 · 짝이 뛰면 같이 뜀 |
| 1.5칸 넘게 벌어짐 | 곧장 붙음 (2.5칸 넘게면 질주) · 붙으면 멈춤 (맴돌지 않음) |
| 짝이 돌격 | 돌격 대상의 옆구리로 질주해 함께 침 (돌격이 부딪혀 끝나도 3초 이어감) · 사수는 짝의 측후방 |
| 짝이 적을 붙듦 | 그 적의 반대 옆 · 뒤 (짝 쪽에서 115°) 로 돌아 포위 — 그동안은 자석 전열로 끌려가지 않음 |
| 짝이 적에게서 물러남 | 같이 적을 마주 본 채 · 방패를 들고 물러남 (뒷걸음이라 조금 처지면 질주로 메움) |
| 짝이 위급 (쓰러짐 · 40% 아래 · 둘 넘게에게 몰림 · 노려진 채 60% 아래) | 곁으로 붙기보다 먼저 그 적을 침 |
| 내가 팔이 닿는 다른 적과 싸우는 중 | 그 싸움 그대로 |
대장-부하는 3칸 (부하만 대장의 측후방으로)

## 개인 본능 — 이제 양쪽 편
- 망치 (붙들린 상대의 옆 · 뒤로) · 망치 · 모루 표시
- '뒤로!' 를 들으면 탱커 뒤로
- 동료 거구의 휘두르기 부채꼴에서 미리 비켜섬
- 총구 피하기 (나를 겨눈 사수의 사선만 비키며 파고듦) — 로그 '🏃 아군 기동' · '🏃 적 기동'
지휘관 전술 (포위 사냥 · 교대 · 양동 · 쐐기 · 철수) · 판 시작 상황 (매복 · 떠돎 · 암살조) 은 적만 그대로
