## 바뀐 것
| 항목 | 내용 |
|---|---|
| 판 위 무기 그림 | 방패는 왼손 (바라보는 쪽 −0.75), 무기는 오른손 (+0.75). 몸이 돌면 같이 돎 |
| 무기 → 그림 | 검 (직접 그림) · 단검 (작은 칼) · 창 🔱 · 둔기 🔨 · 도끼 🪓 · 활 🏹 · 총 🔫 · 마법 🪄 · 거구 맨손 👊 · 그냥 맨손 · 짐승은 안 그림 |
| 명령 칸 | 핵심 (공격 이동 · 막기 · 전열 · 제자리 · 자동 · 명령 취소 · 줍기 · 휘두르기 · 재전달) 은 늘 보임 |
| | ▸ 전술 (정찰 · 암살 · 견제사격 · 지역사격 · 사주경계 · 측면 기동 · 전열 후퇴 · 은신 · 포복 · 우회 · 편대 · 희생 돌격) 은 접어 둠 |
| | ▸ 고르기 · 그 밖 (모두 고르기 · 고르기 풀기 · 동시 선택) 도 접어 둠 |
| | 접고 편 상태는 이 브라우저에 기억 |
| 횃불 단추 | 켬/끔 · 내려놓기 · 던지기 단추를 숨김. 단축키 T · Shift+T · I 는 그대로 |
| 상태 줄 | 한 명을 고르면: ❤ 체력 · 💨 숨 · 🛡 자세 · 막기 방식 (들었는지) · 교전 규칙 · 돌격 안 함 · 포복 · 은신 |
| 일행 상한 | 없앰 (위쪽 "동료 N/12" → "동료 N", 동료 창 "최대 12명" 글 지움) |
