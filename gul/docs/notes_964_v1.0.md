# v9.6.4 짝 붙어 다니기 · 서둘러 줍기 — notes_964_v1.0.md

## 민수 요청
1. 떨어진 장비를 더블클릭하면 서둘러 주우러 감
2. 전우조 · 부하관계는 3칸 넘게 떨어지지 않으려 함. 한 명이 앞으로 나가거나 돌격하면 서둘러 (질주) 돌격 대상의 측면이나 전우의 측후방을 맞춰 따라감
3. (원칙) 적 편만 쓰는 규칙은 없음 — 모든 규칙 · 시스템은 아군 · 적군 동일

## 한 것
- 줍기: 물건을 한 번 누르면 줍기 (예전 그대로) · 0.45초 안에 같은 물건을 다시 누르면 서둘러 (뜀걸음) — 줍기 명령에 hurry
- pairStep (엔진 · 양쪽 편 같은 규칙): 명령이 없고 · 넘어짐 · 붙잡힘 · 휘청 · 피하는 중이 아닌 몸
  - 짝 = 전우 (서로) · 대장 (부하만 대장을 따름 — 대장은 부하에게 끌려가지 않음)
  - 짝이 돌격하면: 근접은 돌격 대상의 옆구리 (짝이 오는 쪽에서 90° — 내가 있는 쪽) 로 질주 → 자리 잡으면 그 적을 침. 돌격이 부딪혀 끝나도 3초 동안 이어감. 사수는 짝의 측후방으로 질주
  - 3칸 넘게 멀어지면: 짝의 측후방 (뒤 1.1칸 · 옆 1칸) 으로 — 짝이 뛰거나 4.5칸 넘게 멀면 질주. 2.2칸까지 붙으면 멈춤
  - 맞붙어 싸우는 중 (적이 팔 닿는 거리) 이거나 막 치려는 적이 코앞이면 그대로
- 로그: 🤝⚡ ○ — 전우 ●의 돌격 → ◎의 옆구리로 질주 · 🤝 ○ — 전우 ● 곁으로 (질주) · 자율 판단 칸에도
- 그 밖: 이 글을 쓰며 찾은 로그 칸 이름 겹침 (표적을 t 로 적어 시각과 겹침) 은 tg 로
