## 총안 다시 (총구가 전열 몸 앞으로)

전 (v9.11 ~ v9.12)
- 빼꼼은 어깨 너머 자리로 걸어간 뒤에야 쐈어요.
- 그 자리가 조금만 비좁아도 '빼꼼 자리 없음'이 되어 평소 오사 규칙으로 돌아갔어요.
- 그래서 쏘지 않거나 오사가 났어요.
- 점사의 다음 발은 앞 전열을 '사선의 동료'로 보고 멈췄어요.
- 전열이 막아 주는 가까운 적이 있으면 사수가 '거리 벌리기' · '일격을 기다림'으로 물러서기만 했어요.

후
- 표적 쪽에 있는 전열(근접 · 지원 인력 아님)과 0.45칸 안이면 바로 총안이에요. 걸어가지 않아요.
- 총구가 그 전열 몸 앞으로 나온다고 봐요.
  - 탄은 그 몸을 지나 나가요. 그 전열은 절대 안 맞아요.
  - 어깨 둘 사이에 서 있으면 둘 다 지나가요.
  - 그 너머의 몸(다른 동료)은 평소 규칙 그대로예요.
- 점사 다음 발도 총안으로 쏴요.
- 전열이 막아 주는 가까운 적에게도 물러서지 않고 총안으로 쏴요.
- 치유사 뒤는 총안이 아니에요.
- 양쪽 편 똑같아요.

같은 판 비교 (전열 바로 뒤 사수, 양쪽 편 × 4판, 5 ~ 6초)

| 경우 | 전: 쏜 / 앞 전열 맞음 / 멈춤 | 후: 쏜 / 앞 전열 맞음 / 멈춤 |
|---|---|---|
| 딱 붙음 | 122 / 0 / 0 | 96 / 0 / 0 |
| 살짝 띄움 (0.35칸) | 0 / 0 / 0 (못 쏨) | 96 / 0 / 0 |
| 옆 어긋남 (0.35칸) | 122 / 0 / 0 | 96 / 0 / 0 |
| 앞 전열이 싸우는 중 | 0 / 0 / 0 (못 쏨) | 36 / 0 / 0 |

- '딱 붙음'에서 쏜 수가 줄어든 건 빼꼼 자리로 오가며 쏘던 것이 없어져서예요. 적 맞힘은 88 → 82로 거의 같아요.

## 막힘 (서로 비집고 버벅거림)

원인
- 같은 자리로 가라는 명령을 받은 무리가 서로 그 한 점을 차지하려고 끝없이 비집었어요.
  - 0.12칸 안에 들어가야만 도착이었어요.
- 먼저 도착한 이가 밀려나면, 지키던 자리('자리로')로 되돌아가 다시 밀었어요.
- 둘 다 치는 중(준비 · 회복)이면 서로 밀지 않아 겹친 채 버텼어요.

바로잡음 (양쪽 편)
- 이어 닿기 도착: 그 자리에 먼저 서 있는 동료(나보다 그 자리에 가까움)에 닿으면 나도 도착이에요.
  - 끝자리 0.5칸 안에서 동료에 닿아도 도착이에요.
- 지키던 자리를 동료가 차지하면, 지금 선 자리를 새 자리로 삼아요.
- 둘 다 치는 중이어도 겹치면 반씩 밀어내요.

같은 판 비교 (audit_jam.js, 6판)

| | 전 | 후 |
|---|---|---|
| 여섯이 한 점으로 — 막힌 초 | 3.17 | 0.20 |
| 여섯이 한 점으로 — 되돌기 | 148 | 5 |
| 여섯이 한 점으로 — 모두 자리 잡음 (중앙) | 7.1초 | 5.2초 (걸어가는 데만 3.5초) |
| 싸우는 무리 — 몸 겹침 평균 | 0.038칸 | 0.017칸 |
| 싸우는 무리 — 막힌 초 | 2.0 | 2.1 (그대로) |
| 엇갈려 지나가기 · 제자리 줄 뚫기 | 막힘 없음 | 막힘 없음 |

- 싸우는 무리의 막힌 초는 그대로예요. 5명이 8초 동안 싸우는 중 한 사람당 0.4초쯤이에요(대부분 '전열 전진'과 '각 잡기').
- '막히면 옆으로 비켜 가기'도 넣어 봤는데 수치가 그대로라 빼 뒀어요.

## 1× = 현실 시간

- 전에는 '1×' 단추가 실제로는 0.25배였어요. ½× = 0.125배, 2× = 0.5배, 4× = 1배.
- 이제 1× = 현실 시간(현실 1초 = 판 1초)이고, ½× · 2× · 4×도 그 배수 그대로예요.
- 브라우저로 잰 값: 1× = 1.08배(첫 프레임 몫), 2× = 2.02배.
- 단추 글과 저장된 설정은 그대로예요.

## 훈련장 ☀ 밝은 맵

- 훈련장 설정(적 시작 무작위 바로 위)에 '☀ 밝은 맵' 칸을 넣었어요.
- 켜면 맵 전체 주변광이 1이 돼요. 횃불 없이도 다 보여요.
- 어둠, 야시, 은신 가운데 어둠에 기대는 몫은 사라져요.
- 끄면 예전처럼 횃불과 빛이 있는 곳만 밝아요.
- 판을 저장하면 같이 남아요.
