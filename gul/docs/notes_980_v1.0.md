## 판 그림
| 항목 | 내용 |
|---|---|
| 무기 = 사거리 | 손에서 바라보는 쪽으로, 끝이 실제로 닿는 곳 (몸 + 사거리) 까지 그림. 창은 길고 단검은 짧음. 준비하면 당기고 치면 뻗음 |
| 무기 모양 | 검 (날 · 손잡이 · 코등이) · 단검 · 창 (자루 + 창날) · 둔기 · 도끼 · 활 (활대 · 시위 · 당기면 화살) · 총 · 지팡이 · 거구 주먹 |
| 방패 | 들면 몸 앞으로 크게 · 내리면 옆에 작게 |
| 세포막 | 서로 닿은 같은 편 둘 이상 = 막 하나로 감쌈 (바깥 테두리만) |
| 돌격 방어 | 뭉침 · 받침 · 돌격이 오는 중이면 막이 굵고 밝아지고 무리 위에 "🛡 돌격 방어 · 버팀 ×N" (실제 계산 값) |
| 밀어붙임 | 뭉침은 가운데로 살짝 당기고 받침은 살짝 겹치게 → 몸끼리 비비며 닿은 채 버팀 (엔진 patch9160) |
