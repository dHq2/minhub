## 1. 생각 순서 (act2 실제 우선순위)

한 병사는 0.2초마다 think, 매 틱 act2를 돈다. act2는 "위에서부터 처음 걸린 것 하나만 하고 끝" 구조다.

| 순서 | 단계 | 편 | 비고 |
|---|---|---|---|
| 1 | 고유 두뇌 (세자르 · 3D 보스 · 굿윌 · 쥐 · 포렌) | 양쪽 | 명령 없을 때 |
| 2 | emergency (약 · 위급 자동) | 양쪽 | 아군 약 명령이 먼저 |

| 4 | 약 받는 중 멈춤 | 양쪽 | |

| 6 | doOrder | 아군 | 플레이어 명령 |
| 7 | rallyStep · offStep | 아군 | 집결 · 연락 두절 |

| 12 | formStep | 아군 | 현재 사실상 꺼짐 |

문제: 앞 단계가 true를 돌려주면 뒤는 아예 안 돈다. 그래서
- pairStep(11)이 전우 쪽으로 걷는 동안 tankAI(19) · 자석 전열(20) · behindCover(24)가 굶는다. 방패병이 전우를 따라가느라 막기를 안 올리는 장면이 여기서 나온다.
- P1a 에서 "중재자" 로 바꿀 대상: 위험 > 명령 > 구조 > 전열 버팀 > 전우조 순으로 점수를 매기고, 이동과 자세(막기)를 따로 고르게 한다.

## 2. 편 대칭 조사 (side_audit.json)

엔진 안에서 `side === 0` / `side === 1` 처럼 편을 직접 보는 곳을 모두 뽑았다.

- 전체 640곳, 함수 297개
- 로그 표시 295 — 문제 없음 (누구 눈에 보이나)

## 3. 명세와 코드가 다른 점

| 명세가 가정한 것 | 실제 코드 |
|---|---|
| 개인 본능이 적 전용 | v9.6.5 에서 이미 양쪽 (hammer · clearSweep · jink · behindCover) |
| 찍기 / 휘두르기 위험 표시 없음 | 이미 있음 (tgTick: 점 · 원 · 선 · 부채꼴, 같은 편도 맞음) |
| 대형(formStep) 이 동작 | 사실상 꺼져 있음 |
| DefenseResolution (방어 판정 한 곳) | 없음. 막기 · 버팀 · 넘어짐이 heavyHit · braceOf · melee 에 흩어짐 |
| timeToWeaponContact (무기 닿을 시간) | 없음. 거리(gap) 와 rng 로만 판단 |
| 일행 상한 | R8.cap 12 로 고정 (표시 · 영입 · 문구 4곳) |

## 4. 확인된 문제

1. pairStep 이 뒤 단계를 굶김 — 1장 참고. (P1a)
2. braceOf 가 붙어 있지 않은 전열 이웃 무게까지 더함 (이웃 질량 0.3 · 0.15). 멀리 서 있어도 버팀이 강해짐. 명세 A18 시나리오. (P1b: 실제로 닿은 이만)
3. 돌격 방어가 없음 — 돌격이 예측돼도 서로 간격을 좁히지 않음. (P1b: 돌격 방어 = 촘촘히 뭉침)
4. 공격돌격 / 방어돌격 구분 없음 — 돌격 명령 하나뿐. (P1b 시험판)

## 5. UI 문제 (사용자 화면 5장 기준)

- 오른쪽 명령 단추가 30개 가까이 한 판에 깔림 (renderOrders0). 자주 쓰는 것과 드문 것이 섞임.
  → 핵심 (이동 · 공격 · 공격돌격 · 방어돌격 · 막기 유지 · 명령 취소) / 전술 / 고유 기술 / 관계 / 고급 으로 나눔.
- 선택한 병사의 상태(자세 · 기력 · 막기 · ROE · 돌격 금지) 가 한눈에 안 보임 → 읽기 전용 상태 줄.
- 판 위에서 병종 · 무기를 알 수 없음 (방패만 표시) → 방패처럼 바라보는 방향에 무기 아이콘 (검 · 창 · 둔기 · 활 · 총 · 단검 · 도끼).
- 횃불 단추가 늘 보임 → 숨김 (단축키는 유지).
- 일행 "최대 12명" → 상한 없앰.
- 전열 · 사선 · 돌격 · 감각 정보를 켜고 끌 수 없음 → 위쪽 겹쳐보기 토글.
- 지켜야 할 것: 네모 칸 판, 초상화.
