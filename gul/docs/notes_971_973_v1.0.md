## v9.7.1 생각 순서 (P1a 1단계)
| 항목 | 내용 |
|---|---|
| 이유 코드 | 저마다 이번에 왜 그 행동을 골랐는지 u.why 로 남김 (명세 6.6). 상태 줄에 "▶ 지금 하는 일" 로 보임 (예: 맞붙어 싸움 · 전우와 붙어 감 · 탱커 — 막아섬 · 돌격 방어) |
| 전우조 순서 | 전우가 걸어가도, 팔 닿을 만한 적이 보이거나 전열에 서서 적을 마주하면 따라가기를 쉼 → 싸움 · 막기 · 전열이 먼저. 짝이 적에게서 물러날 때 "함께 물러남" 은 그대로 |
| 오사 기준 | 거구 휘두르기 · 곡사 아끼기의 "제 편 맞을까 조심" 이 예전엔 적만 셌음 → 양쪽 같은 기준 |
| 고친 버그 | 전우조 뜀 표시 (자리 없음) 가 적의 기동 단계로 새어 위치가 NaN 이 되던 것 (v9.7.1 에서 드러남 · 바로 고침) |
| 고친 버그 | 창을 던진 창병이 빈손으로 "옆으로 돌아 협공" 을 하느라 창을 안 줍던 것 → 빈손은 무장 회복 먼저 |

## v9.7.2 돌격 방어 (P1b 1단계)
| 항목 | 내용 |
|---|---|
| 버팀 = 닿은 몸만 | 옆에 닿음 ×0.3 · 뒤에 닿음 ×0.6 · 그 뒤에 닿은 둘째 줄은 반. 예전엔 1.3칸 안이면 닿지 않아도, 전열 이웃은 떨어져 있어도 무게가 더해졌음 (명세 A18) |
| 시험 수치 | 느슨한 앞줄 (0.6칸 틈) 버팀 ×1.00 · 어깨를 붙이면 ×1.60 · 뭉친 무리 가운데 ×1.86 |
| 돌격 방어 본능 | 곁 (2.2칸) 의 동료에게 돌격이 오면 근접병이 그 뒤 · 옆뒤에 몸을 붙이고 돌격자를 보며 막기를 듦 (양쪽 편). 사수 · 치유는 제 일 그대로. 명령 이동 · 공격 중엔 명령대로 (제자리 · 전열 · 사주경계는 반응) |
| 🧱 뭉침 명령 | 핵심 줄 단추. 고른 무리가 어깨를 붙여 적 쪽으로 섬 — 근접은 앞줄 (여섯까지), 사수는 뒷줄. 막기를 든 채 버티고 닿는 적은 그 자리에서 침. 다른 명령을 주면 풀림 |
| 딜레마 | 뭉치면 돌격에 강하지만 사선이 좁아지고 옆 · 뒤 · 범위 공격에 약함 (명세 5.2) |
