# v8.7.3 결정 (민수 답, 2026-10-22)
- 바로 쏴 · 연타 (바로) 는 오사 감수 그대로 — 민수의 의도된 선택. 바꾸지 않음.
- 주운 무기 · 방패는 다음 맵에도 남김 (지금 그대로). "이 판에서만" = 이 캠페인 (다음 판 = 새 캠페인). 글도 틀린 것 아님.
- 등급 = 희귀도 (도감 성): 친칠라 4성 · 카리우스 5성 — 지금 모두 전투 등급 2 로 ★★ 로 나옴 → 도감 희귀도로.
- "고칠 수 있는 것 다 고쳐줘". 중간에 질문 해도 됨.
- 탕아 공중제비: 감각 · 성능 그대로 (정체성). 메모 규칙 중 "태세 막힘" 만 넣음 (거리 제한 · 5% 튕김은 안 넣음).
- 호레이쇼전이 가장 재밌었음 (완성도). 찐빠 (다시 쥔 근접 = 사수) 만 고침. 회전 투척은 메모대로 넓게 관통.
- 출구: 메모대로 — 보통 맵은 처음부터 열림 · 발견해야 위치를 앎 (출구 명령 = 찾으러) · 정예 · 보스 · 봉인만 잠금.
- 연사 = 최소 사격 간격. 트라카는 단궁이라 다른 궁수 · 장궁병보다 짧음 → 곡사도 같은 짧은 주기로 (지금 곡사는 0.43초 쉼 vs 직사 0.27).
