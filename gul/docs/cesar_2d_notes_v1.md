# 세자르 (Cesar) — 2D 판 전투 정리 노트

- 세자르는 세 아티팩트 중 "미궁 프롤로그" 한 곳에만 있다. 굴의 투기장 (92명 로스터)과 명경기 모음에는 세자르가 없다.
- 코드 안 이름: 유닛 id `cesar`, 전용 두뇌 `cesarBrain`, 기술 상태 `u.cz`, 상수표 `CZ`.
- 줄 번호는 저장된 index.html 기준.
- 단위: "칸" = 전투판 타일. 전투판은 가로 12칸 (`BATTLE_COLS = 12`) × 세로 5칸 (`ROWS = 5`). 속도는 칸/초, 시간은 초.
- 칸을 미터로 바꾸는 공식은 코드에 없다 (사람 기본 키 1.15칸, 카리우스 3m = 3.3칸, 청광묵 130cm = 0.95칸 정도로 일관되지 않음).
- "추정"이라고 적은 곳은 코드를 읽고 내가 해석한 부분이다. 나머지는 코드나 설명 글에 그대로 있는 값이다.

## 3. AI 결정 흐름 (cesarBrain, 8241~8296줄)

매 프레임 이 순서로 판단한다. 앞에서 걸리면 뒤는 안 본다.

1. 권위 흔들림 처리 (4절).
2. 기술을 쓰는 중이면 그 기술을 계속 (`czRun`).
3. 경직 중이거나 대상이 없으면 손을 놓고 일반 AI에 맡김.
4. 눈이 안 내리는 판이면 권위 시전 (첫 0.6초 뒤).
5. 리듬 전환: 탐색 ↔ 딜타임.
6. 빈틈 찌르기 (두 모드 모두).
7. 탐색 중 붙으면: 50%로 원형 베기, 아니면 뒷걸음 점프 연속.
8. 딜타임이면 기술 우선순위 표대로.
9. 사거리 안이면 기본 공격 (일반 AI로 넘김).
10. 아니면 간격을 재며 걷기 (빙글빙글 돎).

### 3-1. 리듬 (페이즈) — 체력 페이즈 · 분노는 없다
- 체력에 따른 2페이즈나 분노 (enrage)는 코드에 없다. 대신 시간으로 도는 두 모드가 번갈아 온다.
- 탐색 (probe) 4.5~7초 (무작위) → 딜타임 (fury, 로그 "👑 세자르가 휘몰아친다") 4.5초 → 탐색 → ... 첫 모드는 탐색 4.5초.

```js
  z.phaseT = (z.phaseT ?? CZ.probe[0]) - sdt;
  if (z.phaseT <= 0){
    z.fury = !z.fury;
    z.phaseT = z.fury ? CZ.fury : CZ.probe[0] + Math.random() * (CZ.probe[1] - CZ.probe[0]);
    if (z.fury){ z.flank = Math.min(z.flank, 0.3); z.rush = Math.min(z.rush, 0.6); logLine('👑 세자르가 휘몰아친다', 'crit'); }
  }
```

### 3-2. 빈틈 찌르기 (두 모드 공통, 최우선 공격)
- 4칸 안에서 경직이 0.15초 넘게 남았거나, 방금 공격해서 공격 간격이 75% 넘게 남은 자 중 가장 가까운 자에게 3배 속도로 달려가 확정 3연격.
- 대기 2.2초. 머리 위 "빈틈" 글자.

```js
  const gap = foes.filter(o => Math.hypot(o.x - u.x, o.y - u.y) < 4 && (o.stun > 0.15 || o.cd > o.st.cd * 0.75)).sort((p1, p2) => Math.hypot(p1.x - u.x, p1.y - u.y) - Math.hypot(p2.x - u.x, p2.y - u.y))[0];
  if (gap && z.punish <= 0){ z.punish = CZ.punish; z.act = { type: 'rush', t: 0, tgt: gap, punish: true }; fxText(u, '빈틈', '#9fd8ff', null, 0.5); return true; }
```

### 3-3. 탐색 중 근접 대응
```js
  if (close.length && !z.fury && z.spin <= 0 && Math.random() < 0.5){ z.act = { type: 'spin', t: 0 }; return true; }   // 탐색 중 붙으면: 베어서 밀어내거나
  if (close.length && z.back <= 0 && !z.fury){ z.act = { type: 'backsteps', t: 0, n: 2 + (Math.random() < 0.4 ? 1 : 0), from: close[0] }; return true; }   // 붙으면 백스텝 연달아 (탐색 중에도)
```
- "붙음" = 1.5칸 안 (`close`). 딜타임의 원형 베기 조건은 1.7칸 안 (`near`).

### 3-4. 딜타임 기술 우선순위 (8273~8283줄)
위에서부터 조건이 맞는 첫 기술을 쓴다. dist = 노리는 대상 (가장 가까운 적)까지 거리.

| 순위 | 기술 | 조건 |
|---|---|---|
| 1 | 원형 베기 | 1.7칸 안에 적 + 대기 끝 |
| 2 | 마구 베기 | 대기 끝 + 최전방 적이 6칸 안 |
| 3 | 하늘 가르기 | 대기 끝 + 1.5 < dist < 7 |
| 4 | 관통 찌르기 | 대기 끝 + 1.3 < dist < 4.5 |
| 5 | 냉기 참격 | 대기 끝 + 2.2 ≤ dist ≤ 5 |
| 6 | 어깨 박치기 | 대기 끝 + dist < 3.3 + 매 프레임 확률 (초당 약 1.5) |
| 7 | 우회 | 대기 끝 + 초당 약 1.5 확률 |
| 8 | 돌진 | 대기 끝 + dist > 2.4 + 초당 약 1.5 확률 |

### 3-5. 평소 이동과 기본 공격

## 4. 권위 — "권위로 신성을 약화"

### 4-1. 무엇을 하나
- 권위 = 눈이 내리고 (`battle.snow = true`) 전장 전체에 신성 제약 (`battle.sealDivine = true`)이 걸린다.
- 신성 제약은 "신성 특성 (`st.divine`)"을 끈다. 아군 · 적 가리지 않는 전장 전체 효과다.

```js
const divineSealed = u => !!(battle && (battle.sealDivine || battle.units.some(e => !e.dead && e.side !== u.side && e.st.sealDivine)));
const divineOn = u => !!(u.st.divine && !divineSealed(u));
const divineCut = (u, dmg) => divineOn(u) && u.st.divine.dr ? Math.max(1, Math.round(dmg * (1 - u.st.divine.dr))) : dmg;
```

### 4-2. 누구에게 걸리나
- 2D 판에서 `divine` 필드를 가진 건 카리우스 하나뿐이다:
  `divine:{ name:'개조된 신체', dr:0.6, bleedRes:0.5 }` — 모든 피해 60% 감소 (평타 · 기술 · 전기 · 낙뢰 포함), 출혈 확률 절반.
- 권위가 걸리면 카리우스의 60% 피해 감소와 출혈 저항이 사라진다. 머리 위 표시가 "✦신성 -60%" → "⛓신성 봉인"으로 바뀐다 (4754~4757줄).
- 훈련장 체크박스 설명도 같은 뜻: "⛓ 신성 제약 필드 (신성 특성이 꺼짐: 카리우스 개조된 신체)".
- 걸리지 않는 것 (코드 확인):
  - 레베카의 불사 (축복:불사A, 초당 2 재생 · 부활)는 `divine`이 아니라 `regen` · `reviveAt`라서 안 꺼짐.
  - 적뢰의 "축복:신성A"는 태그일 뿐 `divine` 필드가 없다. 권위와 상관없다.
  - 어부의 창 신성 특공 (x1.5)은 신성 제약과 상관없이 대상 태그만 본다.
- 세자르 본인에게는 `st.sealDivine`이 없다. 권위는 오로지 전장 플래그로 건다.
- 장비 "노인의 왕관" (머리, 태그 🔆권위, 설명 "신성을 약하게 누른다 (세자르 만큼은 아님)")은 코드에서 그 태그를 읽는 곳을 못 찾았다. 표시만 있고 효과는 아직 없는 것으로 보임 (추정).

### 4-3. 시전 (훈련장에서만 직접 씀)
- 눈이 안 내리는 판이면 시작 0.6초 뒤 손을 든다 (로그 "👑 세자르가 천천히 손을 든다…").
- 손들기 준비 1.1초 (자세 raiseWait): 이때 경직 (stun > 0.05)을 먹이면 끊긴다 → "끊김", 로그 "👑 권위가 끊겼다", 6초 뒤 다시 시도.

```js

```

- 던전 1층 보스전은 `snow: true, seal: true`로 시작한다. 연출로 이미 손을 들었기 때문에 전투 중엔 권위를 시전하지 않는다 (`auth: -1`).

### 4-4. 권위 흔들림 (깨는 방법)
- 눈이 내리는 동안 세자르의 경직이 0.4초 이상이면 (그리고 재사용 대기 cool이 끝났으면) 6초 동안 눈이 멎고 신성 제약이 풀린다.
- 6초가 지나면 다시 눈 + 제약, 그 뒤 4초는 다시 흔들리지 않는다.

```js
  if (z.shaken > 0){
    z.shaken -= sdt;
    if (z.shaken <= 0){ b.snow = true; b.sealDivine = true; z.cool = 4; fxText(u, '권위', '#cfe6ff', 'big'); logLine('❄ 권위가 다시 홀을 채운다. 눈이 내린다', 'crit'); }

    z.shaken = 6; b.snow = false; b.sealDivine = false;
    caption = { text: '권위가 흔들린다', life: 1.8, max: 1.8 };
    logLine('👑 세자르가 휘청인다 — 6초 동안 눈이 멎고 신성이 돌아온다', 'crit');
  }
```

- 0.4초 이상 경직을 주는 것 (코드에서 찾은 예): 저스트 방어 튕겨냄 (공격자 경직 0.9), 역전의 기회 (0.8), GOOD WILL 니킥 (1.0), 적뢰 낙뢰 직격 (1.0), 세자르 자신의 강공 헛침 빈틈 (`WHIFF_GAP = 0.45`, 세자르는 보스라 기본 공격이 늘 강공). 마지막 것은 추정: 헛치면 경직 0.45초가 걸리고 바로 다음 프레임 검사에서 0.4 이상이면 흔들림이 터진다.
- 보통 피격 넉백의 경직 0.18초로는 안 흔들린다.

## 5. 기술 하나하나 (czRun, 8297~8521줄)

공통 규칙:
- 모으는 동안 머리 위 "!" + 바닥 범위가 차오른다 (`CZ_CHARGE = { spin: 0.35, thrust: 0.6, wave: 0.8, ult: 1.0, upcut: 1.0 }`).
- 기술 시전 중 (`CZ_CAST`: auth · shoulder · spin · thrust · ult · upcut · wave)엔 회피율 0, 회피 스텝도 못 밟고, 회피 반격도 없다. 뒷걸음 · 우회 · 돌진은 이동이라 시전으로 치지 않는다.
- "끊김" = 경직 0.05초 넘게 + 슈퍼아머 아님 (`broken()`).
- 슈퍼아머 중엔 경직이 안 걸리고, 버티는 무게가 x4 (420 → 1680kg).

### 5-1. 기본 공격 (긴 검 베기)

- 명중하면 상대 경직 시도 0.45초 (힘 = 420 x 2.5 = 1050kg).
- 연격 35%: 2연격, 그중 35%는 3연격. 빈틈 찌르기면 확정 3연격. 연격 사이 0.12초. 추가타도 공격력 그대로.


- 헛치면 (치는 순간 상대가 사거리 + 0.3칸 밖): 강공 헛침이라 세자르가 0.45초 빈틈 (슈퍼아머가 아닐 때). 상대가 맞기 직전 0.32초 안에 스텝으로 빠졌으면 저스트 회피 → 상대의 확정 반격.

### 5-4. 하늘 가르기 (upcut, 필살) — "⚔ 세자르의 하늘 가르기 — N명 절단"
설명 글: "제자리에서 검을 늘어뜨리고 기운을 모았다가 (슈퍼아머) 세로로 크게 올려벤다. 7칸 직선 위의 모두 (공중 포함)를 두부처럼 썰어 절단 → 경직 → 풀리며 쓰러지고 10초 이동 제약 (느리게 걷기만, 스텝 불가)."

- 조건: 딜타임, 대기 끝, 대상이 1.5칸보다 멀고 7칸보다 가까움. 로그 "👑 세자르가 검을 낮게 늘어뜨리고 숨을 고른다…".

- 방향은 모으는 1초 동안 대상을 계속 따라가고, 베는 순간 고정된다.


- 피해 공격력 x2.2 (66). `grab: true`라서 회피 · 막기를 무시한다 (반격 자세 · 주인공 저스트 입력은 예외). 치명타는 8% 운.

- 경직 1.0초가 끝나는 순간 다운 1.6초 (무게 제한 없음 = 누구든 쓰러짐), 이어서 이동 제약 10초.

| 구간 | 길이 | 내용 |

### 5-7. 마구 베기 (ult, 필살) — "⚔ 세자르 — 마구 베기"

## 9. 피해 계산 요약 (공통 resolveHit)

- 피해 = 공격력 (또는 기술 배수 x 공격력) x 치명타 3 x (1 - 방어력 감소율) x (1 - 막기 감소율). 최소 1.
